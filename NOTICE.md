# FG Studio notices

FG Studio contains an adapted canvas runtime under `reference/infinite-canvas/src/`.
That runtime is based on [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)
and is distributed under the GNU Affero General Public License v3.0 (AGPL-3.0).

This repository contains modifications for FG Studio, including the Supabase
workspace, Wetoken/DeepSeek adapters, usage ledger, pricing display, and the
FG Studio visual shell. The modifications are part of the source tree so that
the corresponding source remains available to users of the deployed service.

The original project copyright and license terms remain applicable to the
adapted canvas runtime. See the [AGPL-3.0 text](https://www.gnu.org/licenses/agpl-3.0.html)
and the [upstream source](https://github.com/basketikun/infinite-canvas) for the
original notices.
