# FG Studio 独立生图设计规格

日期：2026-07-15  
状态：已完成对话评审，待书面规格确认

## 1. 目标

为不创建导演项目的用户提供完整的独立生图入口。用户进入私人创作空间后，可以选择 Wetoken 图片模型、填写提示词、上传参考图并在明确二次确认后生成一张图片。生成任务、结果资产和可信费用账本都必须持久化，页面刷新或离开后仍可恢复。

本功能保持现有 FG Studio 的视觉语言和导演台界面不变，只在 AI 创作台中增加独立生图能力。

## 2. 范围

### 2.1 本期包含

- AI 创作台中的「独立生图」入口。
- 文本生图与参考图生图。
- 每次任务只生成一张图片。
- 最多八张参考图，支持排序和单张删除。
- GPT Image 2、Gemini 3 Pro Image Preview、Gemini 3.1 Flash Image Preview、Gemini 3.1 Flash Lite Image。
- 图片模型、画面比例、提示词、Skill 和 Prompt 模板选择。
- 生成前确认卡，不允许从聊天或参数编辑状态直接调用模型。
- 私人任务历史、私人资产保存和页面恢复。
- 下载、复制提示词、复用参数再次生成、删除结果。
- 可信图片用量记录和管理后台汇总。

### 2.2 后续子项目

- 画布生图：提示词节点、参考图节点、生成节点、结果节点、连线、视口和版本保存。
- 独立视频与视频画布。
- 将私人生成结果发送到导演项目。
- 批量生成两至十张图片。

画布生图不是本期独立生图实现的一部分，但必须复用本期的模型目录、参考图上传、确认机制、生成任务、私人资产和费用账本，不能另建一套平行系统。

## 3. 架构选择

采用专用 Creator API，不改造现有导演项目图片 API。

- 新增 Creator 图片任务接口，负责草稿、确认、任务读取和删除。
- 复用 `lib/ai/image.ts` 中的 Wetoken 图片生成底层。
- 复用 `lib/imageModels.ts` 中的模型与比例映射。
- 复用 `creator_generation_tasks`、`creator_assets`、`creator_workspaces` 和私有 `creator-assets` Storage。
- 复用 `ai_usage_ledger` 的服务端可信写入。
- 现有 `/api/ai/image` 继续只服务导演项目，不改变其请求或响应契约。

这种边界确保私人空间和导演项目的权限、存储与生命周期互不混淆，同时给后续画布生图保留统一任务接口。

## 4. 用户界面

### 4.1 整体布局

沿用现有 AI 创作台的深色玻璃面板、珊瑚色强调和紧凑排版。

- 左栏：创作模式导航及独立生图历史。
- 中栏：空状态、生成状态和大图结果。
- 右栏：模型、比例、参考图、提示词、Skill、Prompt 和生成按钮。
- 窄屏：右侧参数栏变为底部抽屉，结果区优先显示。

导演台和原有对话页面不重做，只启用现有「独立生图」入口并增加对应视图。

### 4.2 参数面板

- 模型选择来自统一图片模型目录。
- 比例根据模型映射为其支持的实际输出尺寸。
- 参考图最多八张，展示缩略图、顺序和删除按钮。
- 提示词不能为空。
- Skill 与 Prompt 模板只辅助构建最终提示词，不会绕过确认步骤。
- 主按钮文案为「生成 1 张」。

### 4.3 确认卡

第一次点击「生成 1 张」只创建草稿任务并打开确认卡。确认卡显示：

- 模型名称。
- 输出比例与实际尺寸。
- 参考图数量。
- 调用次数：一次图片生成。
- 费用提示：当前无法准确预估美元费用，实际费用以 Wetoken 账单为准。

只有点击「确认并生成」才允许服务端调用 Wetoken。取消确认保留当前参数但不产生模型调用和费用记录。

### 4.4 结果与历史

成功结果显示原图、模型、比例、参考图数量和生成时间，并提供：

- 下载原图。
- 复制提示词。
- 复用全部参数创建新的草稿。
- 删除结果。

历史记录按生成任务排序，失败任务保留错误信息但不创建空白资产。删除成功结果需要二次确认，同时删除任务、资产数据库记录、结果文件和任务目录中的参考图；费用账本永久保留，并在任务删除后将任务关联置空。

## 5. 参考图策略

- 最多八张参考图，第九张在客户端和服务端同时拒绝。
- 服务端先创建草稿任务，参考图再上传到该任务专属的私人目录，最后由服务端校验并绑定到任务。
- 不在会话、任务或浏览器历史中持久化 Base64 图片正文。
- 服务端调用模型前重新验证所有参考图路径属于当前用户。
- 允许 JPEG、PNG 和 WebP；其他类型拒绝。
- 单张原文件上限 7 MB，总原文件上限 28 MB。
- 上传前客户端生成缩略预览；生成调用使用私有原文件。
- Wetoken 文档未声明明确的多图张数上限，因此八张是 FG Studio 的产品上限。每个模型上线前执行八张参考图实测；若模型实际限制更低，通过模型配置动态降低上限并在界面说明。

## 6. 任务状态与数据流

### 6.1 创建草稿

1. 客户端提交模型、比例、提示词、参考图文件清单和幂等键。
2. 服务端验证登录用户、私人空间、模型与参数，并创建状态为 `draft` 的 `creator_generation_tasks`。
3. 客户端把参考图上传到当前用户与任务 ID 共同限定的私人目录。
4. 服务端校验文件数量、类型、大小、路径归属和上传完整性，再把参考图路径写入任务请求快照。
5. 返回完整任务摘要供确认卡显示。上传失败的草稿不可确认，删除草稿时同步清理其参考图目录。

创建草稿不得调用 Wetoken，也不得写入费用账本。

### 6.2 确认生成

1. 客户端对草稿任务发出明确确认请求。
2. 服务端用原子条件将当前用户拥有的 `draft` 任务更新为 `submitting`，并写入 `confirmed_at`。
3. 只有成功取得状态转换权的请求可以继续；重复确认返回同一个任务状态，不再次调用。
4. 服务端先写入关联任务 ID 的 `submitted` 可信用量记录。写入失败时终止流程且不调用 Wetoken。
5. 服务端读取私人参考图并调用统一 Wetoken 图片生成器。
6. 成功后上传结果文件、创建 `creator_assets`、更新任务与用量记录为 `succeeded`。
7. 明确失败时更新任务与用量记录为 `failed`；超时或响应不确定时更新为 `unknown`，并记录可展示的错误信息。

### 6.3 恢复与轮询

- 页面加载时读取当前用户最近的图片任务及其资产。
- `submitting` 或 `unknown` 任务不会因页面刷新自动重新调用 Wetoken。
- 客户端可以刷新任务状态，但不能通过轮询触发生成。
- 任务超时或响应不确定时显示「可能已经产生费用」，禁止自动重试。

## 7. 权限与安全

- 所有 Creator API 都要求登录。
- 所有任务、资产和参考图操作都同时按用户与 workspace 限制。
- Storage 路径第一段必须是当前用户 ID。
- 客户端传入的 workspace、任务、资产和 Storage 路径均不能直接信任。
- 服务端生成接口只接受模型目录中的模型与比例组合。
- 提示词、文件数量、文件类型、单文件大小和总大小在服务端再次校验。
- 浏览器不能获得 Wetoken Key 或 Supabase Service Role Key。
- 删除生成结果不删除或篡改费用记录。

## 8. 失败处理与一致性

- 双击或网络重放：同一幂等键只能对应一个任务；同一草稿只能取得一次确认状态转换。
- 参考图上传失败：不创建可确认任务，允许用户重传失败文件。
- 可信用量初始写入失败：终止确认流程，不调用 Wetoken，任务回到可重试状态并显示后台记录异常。
- Wetoken 明确失败：任务与已提交的用量记录更新为 `failed`，不创建资产。
- Wetoken 超时或响应不确定：任务为 `unknown`，标记可能已收费，不自动重试。
- 生成成功但结果 Storage 上传失败：任务保留恢复信息，不伪装为完整成功；后台可以根据临时结果或请求信息人工处理。
- 资产写入失败：任务不进入最终 `succeeded`，并保留错误和生成事实。
- Wetoken 返回成功但用量状态更新失败：不隐藏已经成功的图片结果；初始 `submitted` 记录仍保留，服务端记录告警并允许可信补账。

## 9. 费用与用量

- 每个取得确认状态转换权的图片任务在调用 Wetoken 前对应一条 `submitted` 可信图片用量记录。
- 图片数量固定为一，记录模型、分辨率、用户、workspace 和任务 ID。
- Wetoken 未提供可安全编码的统一图片美元单价前，`cost_source` 保持 `unknown`。
- 界面不得把未知费用显示为零美元或伪造估算值。
- 管理后台继续汇总图片调用次数、模型和状态；未来拿到可靠价格后再增加价格快照和美元估算。

## 10. 测试与验收

### 10.1 行为测试

- 草稿创建不会调用模型或写费用账本。
- 确认请求只触发一次模型调用，重复确认返回同一任务。
- 最多接受八张参考图，第九张被客户端和服务端拒绝。
- 参考图、任务和资产无法跨用户访问。
- 成功生成后任务、资产、Storage 文件和费用记录能够互相对应；明确失败或不确定响应也保留同一条调用记录。
- 失败、超时和存储失败产生正确且可恢复的状态。
- 删除结果清理任务、资产、结果文件与参考图文件，但保留费用记录。
- 刷新页面能恢复历史和非终态任务，不会自动重新生成。

### 10.2 模型契约测试

- GPT Image 2 文生图请求使用生成端点，参考图任务使用多图编辑端点。
- Gemini 图片模型请求包含提示词、参考图和正确比例。
- 四个图片模型分别完成零参考图、一张参考图和八张参考图的受控验证。
- 模型不支持八张时，模型配置限制与界面提示保持一致。

### 10.3 发布验收

- Creator 和图片相关测试全部通过。
- 完整测试、TypeScript 检查和 Next.js 生产构建通过。
- GitHub main 推送成功。
- Vercel 生产部署为 Ready。
- 生产域名登录、草稿确认、一次生成、历史恢复和删除流程完成一次人工验证。

## 11. 后续画布生图边界

画布生图在独立生图稳定后立即设计和实现。它新增 `creator_canvases.graph` 的节点与连线交互，但生成节点必须调用本规格定义的同一套草稿、确认、任务、资产和费用接口。画布不能直接调用 Wetoken，也不能绕过二次确认。

首版画布节点类型固定为：

- 提示词节点。
- 参考图节点。
- 图片生成节点。
- 图片结果节点。

节点图保存视口、位置、连线、参数和对应任务/资产 ID。画布版本、撤销重做和节点级错误恢复在画布子项目中具体定义。
