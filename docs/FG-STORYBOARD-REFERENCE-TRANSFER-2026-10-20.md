# 分镜图参考图传输修复（1.4.8）

## 问题与证据

短剧分镜图按钮直接提交所有已绑定图片，没有本次生成的参考图调整入口。实际失败任务 `04cc8ce3426c34de26e6bc32ad2dabe1` 使用 GPT Image 2.5 Flare，经 WeToken `/v1/images/edits` 提交六张原图，合计 50,442,005 字节。上游 nginx 返回 HTTP 413；相同输入重复提交不会解决。单张较小请求仍有成功记录，不能把该错误解释为余额、模型输出分辨率或媒体 DNS 问题，也不能从该记录断言上游的精确包大小限制。

## 行为

1. 生成分镜图或动作预演，先打开确认窗口。默认保留当前全部参考，可逐张取消或本次不使用参考。
2. 选择只影响本次请求，不写资产解绑，不改变原图、角色版本、已有产物或视频参考。取消后重新编译引用编号，清理未选资产的生成标签，保留作者剧情。
3. 默认优化传输：大图最长边从 2048 开始，必要时降到 1600、1280；WebP 质量从 0.92、0.85、0.75 逐级尝试，保留透明通道和比例，不放大小图。每图目标为 `min(2 MiB, floor(8 MiB / 图片数))`。小于目标的原图保持原字节。
4. 副本作为独立资源通过现有上传 API 保存，以账号、原资源 ID、算法版本和目标大小组成幂等键。只有服务端保存成功、实际大小合格后才允许进入确认；取消或账号切换会停止后续准备。
5. 原图、实际提交图、大小变化、完整 Prompt 与报价可预览。准备阶段仅处理和保存资源，不创建模型任务。确认后才恢复失败阶段并创建生成任务；同一已准备请求使用稳定 operation ID，防止双击或网络响应丢失后重复创建。
6. 任务元数据记载原图和副本 ID、尺寸、大小。413 失败提供直接调整参考图入口，历史失败任务保留。

## 依据与边界

- [OpenAI 图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)支持 GPT Image 输入 PNG、WebP、JPEG。该官方格式说明不代表 WeToken nginx 的请求包限制。
- 本次为前端修复，复用既有权限、资源上传、失败阶段恢复和任务接口，不更改上游限额，也不删除或自动重跑用户任务。
- 8 MiB 是保守传输目标，不能保证所有供应商永不返回 413；无法压缩至目标时停止准备并要求调整，不静默删除参考。

## 验证

- 参考选择与传输专项测试：六图失败输入的体积回归、原图保留、小图复用、取消准备、未持久化/超大副本拒绝、引用编号更新、文本生成和比例保持。
- 隔离 DOM 挂载真实确认组件，验证逐张选择、准备不提交、修改选择作废预览、最终确认、防双击和原绑定保留。网络与模型接口替换为测试依赖。
- 原分镜提示词、镜头引用和视频声线测试回归；仓库 pretest、TypeScript 和正式发布构建。
- 不以 DOM 测试冒充生产 Chrome 人工验收；未自动发起付费模型生成。
