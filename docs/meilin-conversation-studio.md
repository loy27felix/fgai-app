# 美林超级导演：对话制作工作室

目标：一个对话保存一个项目，用户选择一条制作方法，持续通过自然语言修改任意已生成文稿和制作参数。剧本、资产、分镜、逐镜 Prompt、实际图片与视频在同一工作区呈现；图片和视频逐次核对再提交计费任务。

## 四条链路

| 产品名称 | 剧作入口 | 视听制作方法 | 主要特点 |
|---|---|---|---|
| 超级造梦 | short-drama-director 与完整 12 个子技能 | 情境决策→按文戏/商业打戏/玄幻/真人分流→资产→投喂与连续性质检；海外、解说、采风按已选题材挂载 | 完整制作总控，适合强情节漫剧及多类型动作 |
| 超级棱镜 | screenwriting-pipeline 六道流程 | deepwhite-director-shooting-v3-7 导演方法、ZY 影像控制、资产模板与表演指导 | 从概念逐步确认，保留完整原文和版本，支持局部回退 |
| 超级银幕 | screenwriter | Lira 形象→Acting 表演→CineDance 调度；TYGG 的制作事实与逐镜交付方法 | 人物、对白、动机、镜头表现，适合电影感叙事 |
| 超级爆点 | short-drama-factory | 资产模板→script-to-drama-prompt-dev 文戏 / wuxi-action-director-public 武戏→ZY 视觉与质检 | 开场钩子、情绪回合、反转与集尾卡点，适合连续商业短剧 |

每次只加载所选链路、当前阶段和已选类型所需的完整 Skill 与依赖参考文件，记录内容哈希。私有原始 Skill 不放入公开仓库。原包的纯剧作边界保留；由平台适配层衔接媒体 API，不宣称原 Skill 具有媒体生成能力。用户要求的十二模块覆盖各包原始最终投喂外壳，保留导演方法与内容约束；与七段式等格式强绑定的原包机检不能冒充本格式验证。

## 用户交互与状态

1. 左侧项目对话；新建时选择一条链路。支持粘贴想法、剧本，上传剧本或参考素材。美杜莎示例是可选启动文本，不是已有生成结果。
2. 中间对话，明确当前处理、待确认和失败恢复。Agent 提问提供可点选答案，仍可自由补充。用户随时指出要修改的具体资产/镜头/版本。
3. 右侧文稿与媒体区显示最新草稿，完整阅读、编辑、版本切换、批准。自然语言修改生成新版本并自动聚焦对应内容，不重写未请求的章节或镜头。
4. 旧批准版本在新稿获准前仍有效。新稿批准后将依赖旧版的下游标为需复核；不自动覆盖已经生成的图、视频，也不自动花费重做。
5. 视频 Prompt 必须使用用户给定十二模块。每个区间同时写人物动作、镜头运动、背景；零点到指定秒数连续覆盖。锁定对白、时长、素材身份，不擅自更改。
6. 准备生成会建立等待确认的报价。确认面板显示完整 Prompt、真实素材顺序、模型、尺寸/比例/秒数与费用。服务端校验内容摘要、报价时效、成员权限、额度和素材归属后才允许排队。
7. 独立“剧本体检”只运行 06 压力测试，报告结构/留存问题及回退建议，不直接重写、不触发媒体任务。

## 视觉方向

Operate 场景：长时间阅读中文剧本、比较镜头和检查媒体。候选世界依次为剪辑时间线、拍摄通告单、胶片接触印样、剧本修订稿、虚拟摄影棚、导演分镜墙、审片室与导演手稿。沿用方向抽签 key 78680fd0 的第 7 项：审片室与导演手稿。

以暗色审片环境与浅色可切换文稿阅读面为基础；温暖纸白字、琥珀进度、低饱和边界；中文排版、宽留白、工具型布局。状态、批准与素材身份有稳定位置。GSAP 只用于工作区展开和焦点转移，遵循减少动态效果偏好。挑战方向：机票夹的分阶段保留适合审计状态，但不借其复古装饰；商品目录的身份辨识可借鉴，但不用同尺寸卡片填满页面；手册标签借阅读层级，地图借稳定底图与活动层分离。

## 验收

- 不付费生成的服务端集成检查：项目隔离、完整 Skill 载入、阶段批准、局部改稿与版本、过期依赖、图片视频确认摘要、无效引用/时长拦截、失败恢复与相同操作不重复提交。
- 全部旧项目仍可读取；已有素材、媒体、成员与账单保持；模型来自真实启用目录。
- TypeScript、生产构建、既有服务端回归；浏览器可用时做交互验收，否则明确记录未做浏览器实测。
- 同步 GitHub，Mac 工作副本提交并保留六个生产守护任务。上线前检查生成任务、NAS、备份和服务镜像回滚点。
