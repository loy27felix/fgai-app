## 短剧修复

默认固定所选片段时长。仅用户主动选择“按剧情划分”时，允许在支持档位内按剧情缩短。旧分镜保持现状，不自动重做或覆盖历史产物。

批量章节顺序执行，单章错误保留并展示，继续后续章节。停止后续提交不取消已在后台执行的任务；已有分镜默认跳过。

绑定图片资产后自动补齐 `@[asset:ID]`，移除绑定时清理对应自动引用行；手写剧情保留，实际提交依照最终参考图顺序转换。

短剧 GPT 6.1 Sol 结构化任务的服务端总等待预算为至少 30 分钟，客户端对应等待 35 分钟。普通文本及其他模型的预算保留。推理事件与正文分开处理，思考内容不混入分镜 JSON。仍可能遇到供应商侧超时或输出格式错误；本轮不以真实计费生成作为回归验证。

## 协作和数据边界

实时消息只承载临时光标、拖动轮廓和变更通知，不直接持久化画布正文。持久写入继续经过原有鉴权与版本化操作接口，事务提交后才发送云端变更通知。

公开体验账号、私人项目、个人 API Key 和账务仍使用原有隔离边界。成员进入已获授权的画布不会踢走另一个窗口。连接失败会自动重连，云端保存状态继续明确显示，不把本地缓存当作服务端成功。

## 验证范围

- 网关回归：WebSocket 双向转发、身份与 Origin 检查、旧画布编辑令牌不再踢人、广告编辑保护。
