# FG 超级工作台更新说明

**更新周期：2026 年 10 月 7 日—10 月 15 日**
**版本范围：周期开始时 v1.2.18 → 10 月 7 日发布 v1.3.0 → v1.3.17**

本说明按重要程度和功能模块整理本期 main 提交，将同一问题的多次修正合并描述。版本号指第六板块「FG 超级工作台」，主站独立维护版本；开发提交不单独代表生产发布。

## 本期重点

1. **新增美林 · 超级导演**：持续对话修改剧本、角色、画风和分段拍摄，与短剧 Agent 并存。
2. **短剧支持批量制作**：从章节提取资产、生成分镜，到批量提交镜头视频，减少重复点选。
3. **首页整合灵感大厅**：保留原小球和创作区，加入最近画布、历史对话和全屏星球漫游。
4. **画风、导演提示词与参考素材完善**：统一项目风格，补充动作时间轴、运镜和前后段连续性。
5. **个人 GPT 和费用管理**：接入个人 Trings GPT 6.1 Sol，短剧保留 Sonnet 备用；人民币报价、任务恢复和实际费用核对继续完善。

## 新增 · Added

### 1. 美林 · 超级导演

- 左侧新增独立入口，与「短剧 Agent」「广告工作台」平级。可通过持续对话调整故事、立项、剧集圣经、选角、画风、剧本和分段制作。
- 从零创作默认「爆款短剧工厂」；已有剧本可直接粘贴或上传，不必重复走立项问答，也可在 Google AI Studio 起草后导入。
- 支持全剧资产、长期记忆、增删／插入剧集、调整总集数和单集时长。流程记忆随集号同步，用户自己写的要求保留。
- 复用 FG 账号、模型、任务、人民币报价、额度及账单；图片和视频先确认提示词、规格与参考，再提交生成。保留版本、费用明细和原任务恢复。

### 2. 短剧批量制作

- 角色、场景和道具支持批量确认、生图；统一选择模型与规格，逐项修改提示词和参考图，支持只确认、只保存提示词。
- 「剧情章节」新增批量提取资产、生成分镜和视频提示词；已有分镜默认跳过，替换须主动选择，保留逐章入口。
- 「分镜制作」新增批量生成镜头视频，先核对提示词、实际引用、逐项报价、合计与剩余额度，跳过正在生成的镜头。
- 视频提示词支持填写修改意见、补选技能，预览草稿后再应用；分镜图、黑白动作预演、视频分别保留完整提交内容及历史提示词。
- 新产物按「镜头01-分镜图-v1」「镜头01-动作预演-v1」「镜头01-镜头视频-v1」命名。

### 3. 首页、灵感与工具

- 首页下方整合灵感大厅、最近画布；历史对话在创作区右上方，保留原小球和上方创作设计。
- 默认作品网格，新增可选「星球漫游」：密集图片墙、拖动环顾、滚动靠近、全屏浏览，支持图片／视频、用途、来源和模型筛选；全屏内直接查看详情和提示词。
- 新增图片／视频工作台、118 项工具与预设，以及影视剧作工坊知识包。接入完整公司技能包，用于编剧、分镜、表演、电影感画面及商业视觉等任务。
- 投稿增加详情、审核意见与历史；故事库区分已选／未选，项目支持级别、小组、负责人筛选。
- 新增公用体验账号：一次性共用 5 元额度，跨月不恢复，只开放隔离的独立创作、画布和短剧测试。

## 改进 · Improved

### 1. 资产画风与导演提示词

- 资产提取完整使用 `short-drama-asset-prompts` 及模板，结合媒介、身份、物种和全局画风；角色三视图、无人场景、单件道具分开处理，减少混入剧情动作、声音及无关地点。
- 画风参考简化为可选上传 0—6 张图片；生图可选已有风格技能。区分身份、结构与画风参考，生成前可看实际提交内容。
- 剧本转分镜沿用 `script-to-drama-prompt-dev`；武戏结合 `wuxi-action-director-public` 与方向确认。按整体概念、参考绑定、摄影、材质、色光、表演、动作时间轴、声音和负面约束组织视频提示词。
- 加强有效事件密度、动作速率、运镜动机、受击与小型特效因果；明确前后段的站位、朝向、持物、空间和光声承接。成片节奏与穿帮仍需小样检验。
- 新项目默认 Image 2.5、Seedance 2.5／480P，保留已有明确选择。短剧文本优先个人 GPT 6.1 Sol；未绑定或明确额度不足时使用 Sonnet 5.5。超时、一般限流、部分输出不盲目自动重做。

### 2. 个人 GPT、模型设置与费用

- 个人设置新增「GPT 接入」，默认 Trings 地址，个人 Key 服务端加密保存；GPT 6.1 Sol 默认 high 思考。个人上游费用以 Trings 为准，不扣 FG 内部额度。
- WeToken GPT 文本入口停用，GPT Image 生图保留；公司付费备用模型继续受 FG 额度管理。
- 图片尺寸、比例、质量、视频时长、参考素材数量按具体型号和渠道配置，移除不适用的统一限制；Seedance 不再一律硬编码为 9 张参考图。
- 图片／视频展示人民币预估，批量展示单价和合计；供应商已确认、估算、待核对费用分开。只有证据唯一吻合才自动核对，不覆盖人工处理。
- 任务保留 FG 与供应商编号，恢复、下载沿原任务查询，避免自动重复付费提交。

### 3. 导入、交互、音频与数据保护

- 剧本支持 Word、Excel、PDF、TXT、Markdown、CSV 导入，提供原文、排版预览与确认；按剧情或固定时长规划片段，时长受目标模型能力约束。
- 美林操作立即显示等待反馈，AI 回复与剧本逐步显示；立项卡、圣经、表演红线与画风可编辑，修改不自动覆盖产物或收费重生成。
- 新选角、演员说明、表演与红线默认中文；角色原名和英文对白要求保留，旧英文说明可主动翻译。
- 画布节点拖到边缘自动平移；扩大提示词编辑区，保留 @ 引用；关闭生图窗口后可继续等待后台任务。
- Seed Audio、公司 TTS 音色、录音／实时识别与翻译入口更清楚；TTS 真实音色试听，Suno 展示提交、制作、归档和试听。官网验证码仍需人工处理。
- 分享画布可另存独立副本；画布回收站保留 30 天。项目归档至 NAS，复用素材与费用记录保留，离线或有活动任务时推迟物理清理。

## 修复 · Fixed

### 1. 短剧、美林与协作

- 修复带参考图风格保存失败、提示成功但「我的风格」为空、重新打开丢失。
- 修复长章节分镜输出截断、换行重复转义、旧表格粘贴后镜头分隔丢失；恢复任务先读取完整章节，避免旧结果覆盖现有分镜。
- 修复角色设定图参数、保存权限、参考图文件传输与真实 MIME 元数据；自动引用优先当前角色、场景和必要道具，避免混入历史产物。
- 修复美林将普通中文建议误判为 JSON 失败；没有结构化动作的建议正常显示，不自动推断执行修改。
- 修复美林剧目无法删除，以及管理员在成员项目中生成、绑定的素材和视频无法被成员继续使用；无关私人素材仍隔离。
- 修复故事、广告、小说和画布的部分删除／归档及关联约束问题；已选故事依据真实制作项目，避免重复立项。

### 2. 画布、灵感与生成任务

- 修复**放大提示词后，清晰度／比例／时长面板被遮罩挡住**；浮层继承当前编辑器层级，线上已核对调整后同步回节点。
- 修复放大后不能 @ 资产、上传音频缺少原名称、模型选择器保留旧目录。
- 修复音频提取／视频截取误报「结束时间超过视频时长」，改用预览读取的实际时长。
- 修复部分灵感封面、最近画布与自由画布预览空白，以及子路径部署资源白屏。
- 修复删掉对话后刷新又出现；审批、发送只同步当前画布，减少跨画布状态干扰。
- 修复部分素材读取失败、参考素材域名 DNS 解析失败；异步图片已有任务编号时继续查原任务，恢复不自动重新收费提交。

### 3. 广告、综合工作台与小说转视频

- 修复广告 Agent 的结构化输出、工具参数、继续执行身份、重试状态；失败显示终态与预算原因，不再只有等待。
- 修复广告草稿不能填回、已有节点不能继续建草稿、已完成媒体依赖过期链接无法打开。
- 修复综合工作台草稿应用、低清短时长参数、原生媒体下载、完整公司技能读取及工具命名空间。
- 修复普通成员导演台初始化卡住、小说首次启动环境异常、风格缩略图丢失、创建响应丢失后重复项目风险。

### 4. 界面、存储与运行

- 修复玻璃主题文字／图表对比、设置滚动、弹窗截断、剪辑区浅色透底叠字。
- 修复 NAS 不可用时应用被误停、恢复后凭据或工程关联丢失、遗留文本存档阻断恢复；离线保留项目并暂停媒体写入。
- 修复入口重定向、发布资源前缀、运行依赖打包和网关配置读取。
- 修复报表调度锁、缺失任务恢复、月报被日报挤出、日志投递与文本清洗；生产守护进程持续保护。
- 修复不限存储误判、公司音频入口和结果归档；账单依据不足时保留待确认状态。
- 修复音乐队列查询的字段歧义，避免队列列表接口报错。

## 请大家重点测试

1. **同一段 30—60 秒剧本，对比短剧 Agent 与美林**。前者侧重章节、镜头、资产和版本管理，后者侧重持续对话、边做边改，两种入口都保留。
2. **走完整链路**：导入 → 修改设定／画风 → 提取资产 → 分镜 → 改视频提示词 → 核对引用／报价 → 生成／查看。批量先用小样。
3. **看实际效果**：画风与身份一致性、节奏、动作、运镜、受击／小特效，以及前后段站位、持物、光声连续性。
4. **复测易出问题的操作**：参考图风格保存、放大改时长、音频提取、管理员操作后成员接续、关闭窗口后的任务恢复、视频访问。
5. **反馈包含**入口、剧名／项目、模型规格、步骤、预期／实际、截图或任务编号；也说说重复步骤和不需要的功能。失败保留原任务，避免连续重提。
