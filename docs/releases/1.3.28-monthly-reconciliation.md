# 1.3.28 月度账单与自动核销补全

## 查明的剩余记录

1.3.27 恢复授权后，待核对从 352 笔降到 24 笔。继续读取官方账单确认其中 22 笔有相同模型、真实任务编号及“consume / failed / actual_amount: 0”记录。旧实现只导入 success，故漏掉了这些最终零扣款记录；不是可以直接用本地失败状态推断免费。

另外两笔分别是 403 quota_not_enough 与 HTTP 413。均未获得供应商生成任务，没有生成用量。1.3.28 对明确的生成受理前拒绝保存证据并自动核对；有异步任务、输出、Token 或未知错误的请求不进入该规则。

## 自动核销约束

- 失败零扣款保留原始 provider_status、Reference ID、时间与真实零金额，并走现有精确唯一匹配。
- HTTP 401/403/413 的生成前拒绝记录 source、状态码及错误码；403 还需明确鉴权/权限/额度拒绝。每次自动决定留下操作记录。
- 超时、5xx、缺少账单和一般异步失败不能自动判免费。真实费用流水始终优先于“未收费”决定；供应商将原零扣款最终更正为正费用时保留前后审计。
- 供应商尚未返回明确证据时继续自动重试核对，不按时间和金额猜测，不篡改账单以清空列表。

## 月份口径

- 默认本月；可选上个月、任意历史月份或全部月份。
- 请求及项目费用按请求提交时间归集；账户流水按供应商扣款时间归集。统一 Asia/Shanghai，区间左闭右开。
- 筛选在服务器执行，模型与项目条件继续生效；请求导出使用当前月份、模型和搜索条件，并在文件名标明月份。
- 处理记录按其操作发生月份筛选。模型价格为当前参考规则，不冒充历史单价；历史实际金额保留出账时汇率。
- 补齐账单后发现旧逐笔 LATERAL 查询重复计算核销视图，导致接口超过 30 秒。改为 MATERIALIZED 汇总一次再关联请求；真实库返回 938 笔、唯一请求 938、待核对 0，查询耗时 192 ms。

## 火山引擎渠道

已经存在两个生成模型：Seed Audio 1.0、豆包语音合成 2.0。另有三个专用服务：volc.seedasr.sauc.duration、volc.seedasr.auc、volc.speech.mt。

三个专用服务通过流式/异步识别/机器翻译接口执行，不伪装成生音频模型。系统渠道增加服务列表，从当前服务器配置读取启用状态，不暴露凭证，不改变现有任务执行路径。
