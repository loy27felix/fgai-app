# 1.3.29 · 余额、刷新恢复与额度性能

日期：2026-10-18

### 优化

- 管理中心总览使用 WeToken 公司账户真实美元余额，显示更新时间，每分钟自动刷新。读取失败时明确显示暂未更新，保留上次有效金额，避免显示虚假的 0 元。
- 用户每月制作额度改为一次批量归集所有可见成员，账单只汇总一次；历史月份的限额记录也一次读取。保留人民币限额、待出账预留和独立体验账号的额度规则。

### 修复

- 修复工作区刷新返回默认首页。外层网址记录当前内层路由，刷新可回到画布、短剧项目、管理后台子页，保留路由中的月份和筛选条件。
- 页面位置按登录账号分别记录；只接受当前工作区窗口的可信消息及工作区内相对路径。

## 验证范围

- 网关测试覆盖真实供应商币种/单位换算、零余额、缓存、上游异常、权限边界、页面刷新恢复、跨账号存储隔离及外部路径拒绝。
- 批量额度测试覆盖不同成员已核销、预留、待确认金额互不混合，52 个成员仍只执行 5 次费用查询；原有个人、项目与体验账号限额测试保留。
- 构建、生产接口延迟、上线版本及守护进程在部署后核对。浏览器交互验收受当前 Work 浏览器权限设置限制，不能将脚本测试称为浏览器实测。
