# 1.3.27：图片模型与自动对账

## 模型能力来源

- Nano Banana 2.1：<https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1>、<https://ai.google.dev/gemini-api/docs/image-generation>。
- 使用 WeToken 的模型 ID、调用路径和账单信息；不复制其错误的 MiniMax 介绍和能力参数。
- 图像分辨率为 1K / 2K / 4K，不提供 512。固定画幅为 1:1、1:4、1:8、2:3、3:2、3:4、4:1、4:3、4:5、5:4、8:1、9:16、16:9、21:9。
- 自适应时省略 aspectRatio，不发送字符串 auto；有参考图时跟随其比例，无参考图时使用方图。imageSize 独立保持所选清晰度。
- GPT Image 2.5 的 size:auto 不能保证输出 4K；精确 4K 应选择明确尺寸。Flare 偏快速日常生图，Sunburst 偏复杂构图与精细编辑。二者实际效果需要成图验证。

## 自动账单故障及修复

线上旧账单会话于 10 月 14 日失效，供应商账单接口返回 HTTP 401；排查时有 938 次 WeToken 请求、352 笔待核对。旧实现捕获一次授权错误后将进程内 paused 永久置为 true，即使文件授权更新也不恢复；还把所有 HTTP 200 success:false 都当成授权过期。

本版每分钟重读授权、区分临时错误与真实授权失效，保留成功水位，并从最早待核对请求及成功水位之前两天补拉。账单和用量必须完整分页读取；实际账单按唯一流水匹配，文本请求仅在模型、完整用量及完成时间双向唯一时补充匹配。重复导入不重复记账，不以失败状态或时间/金额近似推断免费或费用归属。

对账页可验证原 WeToken 账户访问令牌，使用固定供应商 HTTPS 地址读取用户身份、消费账单及用量。账号必须与原授权一致；验证成功后 AES-256-GCM 加密保存到服务器，密钥来自服务器专用密钥或现有服务器密钥。普通成员无权读取或更新授权。令牌不写入审计记录或响应正文。

仍需提供有效供应商授权；代码修复不能恢复已被供应商撤销的旧 Cookie。模型 API Key 与账户访问令牌用途不同。真实回补结果以运行验收记录为准。
