# FG Studio 1.4.0：对话导演与画布同步

## 用户体验

1. 美林改为项目对话工作区：左边找项目，中间与导演对话，右边阅读剧本、资产、分镜和完整视频 Prompt。自然语言提出修改，新版本自动显示。
2. 新项目选择超级造梦、超级棱镜、超级银幕、超级爆点中的一条链路，不显示 Skill 选择器，也不创建四路比较项目。
3. 独立剧本体检只检查结构、钩子、无效段落与反转；保留原稿，不自动改写和生成媒体。
4. 视频稿统一十二模块；每个区间同时写人物动作、摄影机运动、背景。校验确认秒数、连续覆盖、真实素材和规格。
5. 对话修改和手动编辑保留版本。批准上游新稿后下游提示复核，已经生成的媒体保留。
6. 图片视频先核对完整 Prompt、真实参考图及顺序、模型、尺寸／比例／秒数与报价；确认后后台生成，刷新后继续查看任务结果。
7. 稳定资产 ID 投喂前编译为实际上传顺序的图片编号。修订角色图时自动沿用当前真实图片参考。
8. 历史文稿、真实媒体和成员分享保留。GSAP 用于展现区切换，支持减少动态效果和键盘操作。

## 实现与验证边界

- 方法分配见 [重构设计](../meilin-conversation-studio.md)。完整用户 Skill 私有部署，按阶段读取完整入口与必需参考，记录内容哈希，不公开原包。
- 用户十二模块优先于原包的最终封装格式。七段式等格式专用机检不冒充本格式验证；平台校验结构、时间、引用和规格，不声称已观看或确认实际表演和声音。
- 项目、批准版本、依赖和任务持久保存。复用 FG 身份、预算、费用台账与 NAS，不创建另一套扣费流程。
- 平台当前未连接 Blender、自动调研搜索和离线看板编译，只能交付对应设计文稿。视频按镜头保存播放，不冒充已经完成后期合成。
- 本地浏览器使用真实页面、服务端与数据库，供应商响应替换为标识明确的本地测试数据，无付费媒体调用；已验证对话修改 v1→v2、批准新版本、前景参数窗口与完整报价面板。
- 上线须补齐 CGO 服务端回归、构建、空闲检查、备份、运行版本、旧项目读取及 Git 同步；完成前不能称为已上线。
