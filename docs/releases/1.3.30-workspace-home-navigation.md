# 1.3.30 · 返回工作台导航修复

日期：2026-10-18

### 修复

- 修复导演工作台“返回 FG 工作台”无法回到首页的问题。相同文档内清空网址位置时也立即打开首页；新打开工作台首页不再被上次导演位置覆盖。
- 保留刷新恢复当前位置：网址中的画布、项目、后台子页及筛选仍可恢复；仅真正的重新加载允许使用按账号保存的位置作为回退。

## 原因及验证

导演端使用正确的 `_top /production-lab` 返回链接。此前外层页面忽略空 hash 导航，并在新的首页导航中无条件恢复上次位置，两条路径都可能把用户留在导演页。

回归测试在修复前重现两条失败，修复后通过；同时保留画布、章节、管理后台、月份筛选的刷新恢复及可信来源检查。上线后验证实际返回的页面脚本。浏览器工具重新检查仍返回 `Local browser use is disabled in Work settings`，不将脚本核验称为浏览器点击实测。
