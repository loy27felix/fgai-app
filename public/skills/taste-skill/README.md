# taste-skill（已应用于 FG Studio 前端）
来源：https://github.com/Leonxlnx/taste-skill
已抓取并应用的规则集：
- design-taste-frontend（主）：单强调色、禁紫蓝霓虹、禁纯黑、禁 Inter、非对称/Bento、液态玻璃内描边、禁 emoji。
- high-end-visual-design（soft）：双层包边卡片、按钮套按钮、悬浮玻璃导航、大留白、自定义缓动、模糊上浮入场。
- gpt-taste（最严格）：零 emoji、无缝 Bento(grid-flow-dense)、2-3 行标题铁律、AIDA 结构、巨幅留白、禁廉价 meta 标签。
