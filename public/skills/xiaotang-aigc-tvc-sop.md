# 小糖 AIGC TVC SOP

用于把商业需求转成可执行的 AIGC 广告方案：先锁定商业信息，再组织画面、节奏、提示词和质量检查。默认不让模型生成可读文字、品牌 logo 或包装文案；真实品牌元素由后期叠加。

## 先收集

- 产品/服务、目标人群、投放渠道、时长、画幅、核心卖点和禁止项。
- 可用素材、必须保留的品牌事实、人物与产品连续性要求。

## 输出结构

1. 一句话创意核心：产品如何解决一个真实瞬间。
2. 时间码分镜：每镜写清时长、构图、机位、动作、情绪与转场。
3. 五段画面弧线：环境建立 → 人物/需求 → 记忆点或图腾 → 产品暗示 → 完整揭示与收束。
4. 每镜提示词：主体、动作、镜头、光线、材质、空间、节奏、负向限制。
5. QA：时长、产品事实、人物一致性、镜头连续性、无乱码文字/错误 logo/水印。

## 六要素镜头公式

【主体】在【空间】执行【动作】，镜头以【机位/焦段/运动】观察；【光线/色彩】塑造【情绪】，画面强调【材质/关键细节】，并明确【连续性与负向限制】。

## 质检清单

- 是否每 2–4 秒出现一次可见推进？
- 是否从产品卖点而非纯装饰开始？
- 是否锁定角色服装、道具、空间和光向？
- 是否避免模型自行生成字幕、logo、包装文字和水印？
