# FG 广告工作台

第六板块中的独立广告制作工作区，复用原版 AdCraft 的 ReactFlow 画布、Pi Agent、技能与时间线。上游源码位于 `upstream/`，基线为 `GML-MMGroup/AdCraft@79405b3773942b5d41cea65ece3d605be6056ceb`；保留源码许可与出处。

用户路径：左侧 **广告工作台 → 新建广告项目 → 填写需求、小组、预算和可选故事 → 打开制作工作区**。原版工作区内继续规划、编写脚本、制作图像与视频、编辑和导出；重新打开恢复原工程。

账号复用 FG 登录。项目仅负责人、当前小组成员、明确授权成员和超级管理员可访问。每次 API、素材和模型请求都执行服务端权限检查，浏览器没有 WeToken 密钥。调组后立即改变当前访问权限，历史账单保留调用时的归属。

首批适配 GPT 5.6、Seedream Lite、SD2-fast。文本工具调用、图片和视频任务进入现有 FG 队列，记录实际操作人、项目和 Reference ID，复用授权会话的人民币账单核销。参数价格由现有 FG 费率表计算；待核销金额不能当作实际零费用。独立 BGM/TTS 模型未配置，音频可使用上传素材及 SD2 原生音轨。

媒体原文件与生成结果存储在 NAS `/Volumes/FgStudio/media/adcraft/workspaces/<workspace>`；SQLite 工程数据库存储于 Mac mini 的 Docker 持久卷，写入后及每分钟做一致性备份到 NAS，启动时可恢复。NAS 标记缺失时拒绝写入。备份、内部记录和数据库不通过媒体接口开放。云端模型任务使用 FG 频控；本机 FFmpeg 合成最多 2 个并行。

验收不调用收费模型：网关模拟覆盖三种请求、工具调用、预算拒绝与重复提交；实际原版服务验证工程创建、参考图 NAS 上传、跨工程拒绝和数据库备份恢复。完整付费成片不自动重跑。

部署使用 `deploy/Dockerfile.{api,web}` 与上游 Agent Dockerfile，仅新增第六板块三个私有容器，外部通过现有 FG 网关进入。前五板块的服务和数据库不改动。
