# FG 导演工作台

从 FG 第六板块左侧“导演工作台”打开。使用 FG 登录状态，不需要员工的个人 Claude 或 Codex 账号。首次打开由服务器准备独立运行环境。

## 创作

在原生界面创建工程，上传剧本、小说或产品资料，从导演助手开始构思、分镜、人物与场景资产制作，再生成镜头并进入剪辑。导演助手的模型菜单可选择公司配置的文本模型。默认图片为 Seedream Lite，默认视频为 Seedance Fast。

所有模型请求经 FG 的生成入口，受用户当月额度、团队并发和请求频率保护。费用在 FG 人民币账单中核销；子应用的用量和报价是估算。模型未声明能力、不可报价或材料参数不支持时会报告具体原因，不展示虚假的零费用。配音需要先接入可用的公司语音服务，当前不能假定旁白已经配置。

工程目录位于 NAS `FgStudio/media/arcreel/users/<FG 用户 ID>`。每位员工的执行环境只挂载自己的目录，状态数据库位于独立 Docker 数据卷，并在该卷中保存快照。主机目录、Docker 管理接口、上游渠道密钥和其他员工工程不交给执行环境。原生 MCP 技能负责工程、分镜和剪辑操作；任意 Bash 命令不开放。

## 技术来源

上游完整源码、许可证与适配部署层见同级 `upstream`、`deploy`、`SOURCE.md`。导演台顶栏提供对应源码包下载。FG 主页面仍为 `https://192.168.0.99:3000/production-lab`，3017 是内嵌导演子应用的 HTTPS 端口。
