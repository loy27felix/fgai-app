# 服务商目录

本目录随上游导入，用于目录格式与离线回归；`catalog.json` 是上游托管目录样例，`catalog.example.json` 是最小格式示例。FG 只有管理员打开目录时才读取远程快照，不会自动创建或更换现有渠道。

样例包含秘塔，展示期见 JSON。卡片按北京时间显示起止时间、到期日和剩余天数。样例中的宣传与价格来自上游，不代表 FG 已核验可用的公司渠道或实际账单。

长期推广配置：在服务商对象中设置 `"permanent": true`，保留 `startsAt`，可以省略 `endsAt`。此时到达开始时间后持续展示，卡片显示“长期推广 · 无到期日”。定期推广保持 `permanent` 不填或为 `false`，必须设置晚于开始时间的 `endsAt`。秘塔仍按已确认的一年展示，没有自动改为长期。平台 Logo 从 https://metaso.cn 官网左上角内联 SVG 采集，保存在 `logos/metaso.svg`；模型 Logo 使用产品现有的 `minimax` 标识。

样例价格按每秒计费：480P 0.075 元、768P 0.09 元、1440P（2K）0.18 元。目录换算采用 1 元 = 1 积分；管理员须核对服务商最新报价与 FG 售价后再接入。

发布时目录结构应为：

```
/srv/yingce-catalog/v1/catalog.json
/srv/yingce-catalog/v1/logos/metaso.svg
```

FG 未执行本目录中的 Caddy 部署示例。目录拉取超时为 3 秒，失败后普通读取冷却 30 秒，手动刷新仍可立即尝试；并发刷新共享请求，已有缓存立即返回。当前样例能力支持 4–30 秒、默认 15 秒，参考图/视频/音频为 9/3/3。模型描述中的“2K 最长 15 秒”尚未增加按分辨率的联合校验，不能将描述视为已实现的限制。真实 Key 核验与生成效果需在管理员选定渠道后验收。
