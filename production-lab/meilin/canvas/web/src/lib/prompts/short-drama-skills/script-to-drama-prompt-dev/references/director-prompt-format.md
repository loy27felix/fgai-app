# FG 导演提示词合同 v2

替换方括号内说明，输出实际剧情，不能输出占位模板。每个片段独立可用；所有区块都保留，确实不适用的内容简短说明，不编造人物、技术参数或音效。项目画风和原作身份优先；写实、动画、纪录片分别采用对应媒介的表演和材质。不得套用默认中国角色。

```text
[项目名称]
[总时长]秒｜[一镜到底／多镜头]｜[类型与表演风格]

【视频整体概念】
类型：题材、媒介和拍摄质感。
表演风格：人物如何表现，克制、生活化或风格化的具体尺度。
时长：实际总时长秒。
画幅与帧率：所选横竖比例、目标画质与运动节奏；模型未提供帧率控制时不声称可提交该参数。
剪辑方法：镜头从何处开始，依次跟随谁，经过哪些空间，最终停在什么画面。一镜到底写完整摄影路线及真实通道；多镜头明确切镜动机与前后画面承接。
时间与天气：时间、季节、天气及可见表现。
地点：具体环境、边界、出入口、关键道具和通行路线。
整体叙事：起始状态 → 触发事件 → 人物行动 → 变化或发现 → 结束状态，信息揭示和情绪推进。
衔接：具体写出上一段结束状态、本段开场状态、切入方式及理由。可用同地空镜、道具插入或其他角色反应开场；画外动作与声音持续推进，回到人物时位置、道具、时间必须对得上，不能借空镜瞬移。

【参考图绑定】
人物A严格参考：实际素材名称或稳定引用，锁定面部、发型、体型、服装、配饰和关键道具。
人物B严格参考：实际素材及锁定范围；没有B时注明单人。
场景／道具／色彩参考：逐张说明身份、服装、空间、道具或色调职责，继承内容和仅作气质参考的内容分开。
运动、遮挡、短暂失焦后仍为同一人物与服装道具状态。没有可用素材时明确无已绑定图片，禁止虚构编号。

【摄影参数与镜头控制】
镜头：焦距或视角特征，固定焦距或允许变焦。
景深：主体与背景清晰程度。
机位：初始位置、高度、与主体距离。
运动路径：为何移动、何时启动、路线、速度及落点，真实通道与障碍。
转向节奏：启动 → 加速 → 减速 → 稳定，保留合理惯性。
稳定性：固定、稳定器或手持；手持写步伐起伏、呼吸位移和允许晃动幅度。
焦点控制：对象与交接时机，失焦由具体动作或遮挡触发并及时恢复。
曝光与白平衡：按需要填写曝光倾向及相关参数，不必写满所有参数。

【画面整体视觉方向】
用完整段落统一媒介、真实程度、精致或粗粝程度、观察距离、景深、颗粒和运动质感；说明清晰与柔化的细节及避免的倾向。

【真实皮肤／主体材质】
写实保留毛孔、纹路、肤色差异；布料褶皱、磨损、反光和重量。动画或非人物改为相应媒介规则；按风格说明磨皮、美颜、蜡质或过度光滑的禁用范围。

【画面色彩与逻辑】
主色、辅色、强调色的范围和用途；饱和度、明暗、肤色、黑白处理。同光照下转向、遮挡和移动不造成无依据的白平衡、色温或色彩跳变。

【光影】
主光真实来源、位置、方向、软硬和覆盖；墙地反射；面部身体受光与自然阴影；前中后景明暗。人物移动转头时受光随位置朝向合理变化，光源固定在真实场景中。

【背景人物活动】
职责、位置、动作与错时节奏；部分人物可静止。谁关注主角、谁继续工作，叙事动作与环境活动分开。不得复制主角身份；人数变化须有进入、离开或遮挡原因。无人场景注明无背景人物。

【主角的眨眼与错时表演】
自然眨眼，无固定间隔和多人同步。视线先注意目标再转头、肩背跟随；脚步重心先调整再转身；停步缩短步幅，惯性前移再稳定。眼神、眉、唇、下颌和呼吸顺序响应。双人反应有先后。道具互动写观察、接触、操作、交接、松手、结果、使用哪只手及接替条件。

【[总时长]秒分镜／动作时间轴】
0—[结束时间]秒｜本段叙事任务
人物动作：位置、朝向、视线、动作先后、互动及结束状态。
镜头运动：位置、高度、距离、路线、速度、构图与焦点交接。
背景：可见空间、环境活动、背景反应和道具状态。

[上一段结束时间]—[下一个结束时间]秒｜下一任务
人物动作：从前一时段结束状态继续，写动作及结果。
镜头运动：连续镜头承接机位；切镜重新建立人物空间关系。
背景：承接环境状态，新增信息及持续动作。

继续完整覆盖到实际总时长，无时间空洞、重叠、倒序或均分硬凑。最后一段明确人物位置姿态、镜头、道具和信息的最终状态，并提供下一片段可用的入口。

【声音设计】
音乐：是否需要、进入退出、模型生成或后期添加；默认无额外配乐，按已确认需求调整。
环境底声；人群来源、语言、清晰度与距离；脚步、衣料、呼吸；接触、操作、碰撞对应音效；电子声仅在剧情需要时写来源、次数和音量。
空间关系：摄影机靠近远离时，声源强弱、方向和清晰度合理变化。
对白：角色、原文完整台词、时间段；没有对白明确注明。基础声线跨段逐字复用，情绪只改语气呼吸停顿。视觉切到倾听者或空镜时说明原角色画外音继续，不能漏词、复述或两人抢同一句话。

【负面约束】
身份：不换脸、融合身份、无故改变发型衣服。
动作：无穿模、异常手指、接触错误、动作先后颠倒。
空间：不瞬移、交换位置、无故反转方向或道具消失。
摄影：与本片拍法相关的禁用切镜、变焦、运动和失焦。
画面：与目标风格冲突的材质、色彩、光线。
声音：不需要的音乐音效、错误声源方向和动作音不同步。
其他：依项目确定字幕、文字、Logo规则；默认无字幕、叠字、Logo、水印。
```

## 道具交接与摄影通道范例（仅示例，不移植到无关剧情）

16—18秒｜A、B与镜头共同穿越警戒线

人物动作：A右手抬线，屈膝、低头、收下巴，先右脚后左脚穿过。B左手从后方接住；A确认B托住后才松手。B保持抬线，低头跟随。

镜头运动：C随A降至约1.2米，从A抬出的真实空隙中后退通过。警戒带斜向掠过画面短暂虚化。通过后C缓升、右漂，焦点由A脸转至肩背。

背景：制服警察侧身让出通道；一人拍摄地面，另一人向同事递证物袋。

## 打戏设计与跨段核对

仅在用户确认的打戏方向存在时加载 wuxi-action-director-public。先锁定攻防人物、先手、武器、距离、轴线、起止状态、胜负/目标、升级节点、允许特效及禁用项。利用该 Skill 的动作因果、互动反馈、能量边界设计，不强行生成30秒8段。仍用上述导演格式和本次模型支持的时长输出。

为每一片段建立结束状态记录：角色位置/朝向/姿态/手部与道具/伤势与服装/空间轴线/光声。下一片段逐项核对。切换到空镜、反应或其他人物只能隐藏剪辑接点，不能消除前段已经发生的动作与结果。
