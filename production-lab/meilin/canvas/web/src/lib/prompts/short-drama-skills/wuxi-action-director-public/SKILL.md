# 武戏导演（公开版）

给图生视频模型（多参考图、用 @图片1、@图片2 指代参考图的那一类）写国风、玄幻战斗视频提示词的一套方法。全部结论来自几十轮“写稿 → 生成 → 看片 → 改”的实测。

**怎么用**：把这份文档整个交给 AI，当作它写提示词的规范；也可以放进 Claude 的技能目录，当作 SKILL.md 使用。

---

## 〇、先说清楚几件事

1. **导演简写，不写逐镜细写**。每个镜头都写满站位、左右、米数、起幅落幅的“逐镜细写”，一篇五六千字，生成出来反而保守、呆板。导演简写只写导演意图和看得见的东西，动作细节交给模型，效果明显更好。
2. **模型会照字面画**。写“一条河”，它就画一条带子；写“化作一道光”，它就画一团糊影；写“定在半空”，它就真的停住。每一个量词和动词都要先想清楚，它会被画成什么。
3. **节奏少而准**。30秒里塞太多新东西，模型来不及生成，结果就是混乱。多数时间重复加密同一种交锋，升级集中在最后三分之一。
4. **内容从图里长出来**。不套固定的特效词库，用了词库，每一稿都会长成一个样。能量、对手、场景锚点、奇观，都从这一张参考图里取，再往神通和天地的尺度上放大。

---

## 一、判断要做什么

| 对方说 | 做什么 |
|---|---|
| “你有什么想法”“先想想” | 只给方案：主线、双方打法、高潮画面、时间分配，不写完整提示词 |
| “出一版”“按这张图写” | 直接写完整提示词 |
| “反推这个视频” | 按第八节做 |
| 发来旧提示词，“改成这个格式” | 按第九节做：原稿的招式编排和卖点全部保留，只换掉会出问题的说法 |
| 一分钟以上，有故事、有台词 | 按第七节：先交设计，确认后按30秒一段写 |

- 对方这次明确提出的要求，优先于本文的一切规则。
- 改稿只改指出的部分；对方贴回旧版要求回退时，以贴回的为基线做最小改动。

---

## 二、读图：从图里取五样东西

| 问题 | 例子：红衣火剑客和伏在草里的狐耳少女 | 在稿子里变成 |
|---|---|---|
| 人物是谁，拿着什么，姿态像在做什么 | 红衣剑客，剑在燃烧；狐耳少女伏在草里窥视 | 他用火剑打；开场就是她在潜伏 |
| 图里本来有哪些能量、元素、材质 | 剑上的赤焰，少女身边的粉色光屑，石门的冷蓝光 | 三种能量，各管一件事 |
| 背景里什么能变成对手或威胁 | 石门前的怪物剪影 | 从石门涌出的怪物群、破门的巨兽 |
| 场景里什么能当锚点和反馈介质 | 石门、长草、野花、碎石小径 | 石门做锚点；草被压倒，花被点燃 |
| 图里正在发生什么 | 少女在躲，怪物在游荡 | 开场的“潜伏与暴露” |

图里没有的东西尽量不加。要加，就从图里已有的元素延伸，例如狐火融进剑焰，才有了“赤粉融合火焰”。对方点名要、图里却没有的特效，颜色和材质也从图里找。

神话和民间人物可以直接写名字。游戏、动漫、现代影视里的知名形象只写外观，不写名字，兵器也只写外观、不写专名。

## 三、设计：先定节奏曲线

30秒写**8段**，每段3—4秒，最后一段可到6秒；某几段内容特别满时可以写7段。写到9段以上，模型来不及生成。不足30秒的片子，每段按2—4秒排。

| 段的类型 | 例子 | 数量 |
|---|---|---|
| 开场爆发 | 0—3秒 潜伏与暴露 | 1段 |
| 同一种交锋，逐段加密、加重 | 登场、围攻、第二人介入、巨兽压制 | 约4段 |
| 升级与终结 | 融合、大招、终结 | 最后三分之一，约3段 |

**上限**
- **新机制、变大、换地点**，各最多1次，都放在最后三分之一（倒数三段）。前面的交锋段不引入新东西，只让同一种打法更快、更密、更重。首领在中段登场、正面交手，算交锋加重。换地点放在倒数第二段，不和终结挤在一起。
  - **新机制**：第一次出现的招式或规则。同一个技能用得更多、更快、更重，只算加密。
  - **变大**：尺寸跳级，例如人变成法相、几道剑气变成遮天。
  - **换地点**：已建立的地标全部离开画面。同一片湖上，从船头打到湖心不算。
  - 长片续段开场时，承接上一段钩子的那次升级算上一段的。
- **能量**不超过3种，同时出手的不超过2种。角色的附属物和材质算他本身。
- **不排“拉开看全局”的局势图段**：镜头拔高，看几路龙群包抄、一道火线在林海里穿梭、旋涡图案，人缩成一个点或一条线，看不清一招打中了谁。这种段实测“莫名其妙”，删掉后整片反而更好。大场面必须是某一招打出来的后果。
- **巨物要用超远视角**：法宝斗法、法相、盘山巨龙、水与墨堆成的巨人，只有镜头退到数里外、人只剩一粒火点时，才显得庞大。区别在画面主体：超远视角里，是一个巨物在做一件具体的事；局势图里，是许多小单位在走位。
- **交锋有来有回**：一方出手，另一方当场有看得见的应对，再反击。强势一方的“一步不退”只指脚下不退，手上照样还击；否则会变成“只有一方在打，另一方完全没反馈”。
- **卖点**：速度型越打越快、越打越密；力量型打在实体上，越打越重；体量型才用巨物和法相。对手可以压制主角一小段，但不能让主角的卖点整段落空。速度型对决不要写成武器变大、互相顶住对推。
- **敌人**：一打多时只写功能：围攻、扑咬、遮挡、受击、击飞。一对一时，对手的招式也从图里来。图里的配角不出手，只当反馈锚点。
- **写实与见血**：见血只在改变局面的时刻出现，全片一两次。写实题材的扩散，靠气浪、刀风带动环境。

**视角与朝向**
- 视角固定在一个主角身上；斗法阶段跟着法宝或法相走。一对一、两人分量相当时，选描述里点名更多、图里画面比重更大的一方。
- **要防的是正对镜头的摆拍**。参考图多是正脸的定妆照，不写朝向，模型就会让人物一直正对镜头，像在打观众。
- 全局写一句**朝向句**，只管比例：“交锋时男主面朝对手打，镜头多从侧面、侧后方拍，出招时可以露出正脸和侧脸，不做正对镜头的摆拍。”（“男主”“对手”换成这一稿的角色名。）
- **全局不写“背对镜头”**：写进全局，整片都会是背影。
- **朝向句只管交锋**。升空、举兵器、变身、对峙这些不是交锋的段落，全局管不到，每段要在镜头小字里自己写镜头在主角哪一侧；背影就写在这些段落里，例如“镜头在男主身后，越过男主的肩头看对手”。没写方位的段，主角多半会正对镜头摆拍。
- 交锋时，把镜头逼退的是对手的攻势和冲击。写成“被主角逼退”“迎着主角后退”，镜头就站到了主角对面，主角会朝着镜头出手。

**结局**
- 终结一击放在最后一段，写完冲击扩散就结束。
- 不写回到开场画面、收势摆拍、总结段；也不写“最后镜头落回定型”，这句很容易把模型引回开场画面。
- 最后一段只放终结一击、扩散和最多一两句台词；敌首逃走、本体离去这类收尾，写成扩散里的一句。
- 长片前几段的结尾是钩子：停在即将命中的一瞬，不命中、不爆炸。

反面例子：一篇九段，每段一个新机制、一段比一段大，4种能量，变大两次，换地点两次，视角在两人之间来回切。生成出来“完全没有节奏感，很混乱”。

## 四、写

### 开头部分：只写“是什么样”，不写“会发生什么”

开头写了会发生什么，模型就只照着开头生成，正文8段被略过。开头不限长度，只描述人、场景、特效、技能各是什么样；怎么打、镜头怎么走、声音怎么变，都写在正文各段里。

顺序：参考分工 → 场景 → 能量锁定 → 技能 → 群体结构（需要时）→ 全局一段。

1. **参考分工**
   - 每张图写成“使用@图片N作为……参考”，紧接着写清这张图里是什么样、取什么不取什么。场景图的描述放在场景段时，场景段开头写“@图片N的场景是……”。只挂一个@、不写图里是什么，模型对不上号。
   - 写清谁是谁，加一句“全程不变脸、不换装、不改变身材比例”。只有一张图时写“使用@图片1作为人物与场景参考”。
   - 多张图时，**先定唯一一个场景**。模型会直接把参考图的背景读成画面，中途会莫名切到某张人物图的背景。只管人物的图，紧跟一句“只取人物，不取背景”；场景只能有一个出处：一张场景图，或者“场景只按下面的文字”。
   - **形态参考图**：文字说不清的大型特效、终结画面，先生成一张形态参考图，挂成 @图片N。@旁边写清图里画的是什么、构图怎样（谁在左谁在右、镜头从哪里往哪里看），写明“只参考形态、质感、颜色和构图，场景仍是……”；图里和本片角色长相不同的东西写明不取。正文里它出现的那一段**再@一次**，而且写在过程的终点（见第五节“终结画面挂了参考图”）。只在开头挂一句，模型不知道它在哪一刻出现。
   - 写一句“图片上的水印和文字不进画面”。
2. **场景**：近、中、远三层材质和锚点，写出纵深（数公里）和一组天地色彩对冲，加一句“色彩稳定，不跳色”。巨物写数字尺度，并和地标比较（“龙头比一座楼阁还大”）。
3. **能量锁定**：每种能量写清材质、颜色、明确不是什么（“不是火焰，不是光柱”）、和服饰的色彩对冲。只描述它长什么样，它贴在哪、什么时候炸开，留到正文发生时再写。
4. **技能**：每人两三个技能，只出手一次的配角写一个。每个技能描述它本身是什么样子，正文里用技能名调用，并写明“技能名只用来定义画面，画面里不出现任何文字”。
5. **群体结构**：一打多、龙群、万剑时才写，见第五节“鱼群结构”。
6. **全局一段**：
   - 什么战斗、在哪里；
   - 朝向句；
   - 打法走向，前半怎么打、后面怎么升级、最后一击是什么，各一个分句；
   - “动作全程不停”“无血腥”“无配乐”这类一句话的要求；
   - 有台词时，写明语言和声线。

因果链、空间关系、镜头远近、声音清单，是写正文前自己理清的设计工具，保证每段接得上、距离不乱、音效有来处，但**不写进提示词**。空间关系包括每个人脚下是什么（沙、浅水、石板、半空）：上一段砸进浅滩，下一段就从水里起身；要回到沙滩，写一个动作带过去。脚下一段是水、一段是沙，模型会乱。

### 正文：每段五个成分

```
【时间】功能标题。{镜头小字}。{有来有回的交锋}。{特效过程与环境反馈}。音效：{A} → {B}。
```

1. **功能标题**：这一段在节奏里的作用，两到四个字。
2. **镜头小字**：先写镜头在主角哪一侧（侧面、侧后、身后越过肩头），再写镜头的感受，不写机位名。每段都写方位，升空、举兵器、变身这些不是交锋的段落尤其要写。把镜头当成被卷进打斗的人：它被什么推开、拖着跑、逼退、震得一跳、被碎石遮住；它追不上什么，只捕捉到什么痕迹。机位名只是标签，真正让画面有速度感的是这句感受，例如“镜头仿佛被空气激波强行推开，艰难捕捉人物突破音障的残影”。远景写距离感：冲击晚半拍才传到，脚边碎石跟着一跳。
3. **有来有回的交锋**：每段两到四个连续动作，一串动词带过，不写记账式的伤害。只写一个动作，段落会显得慢、显得空。
   - 开场段只写一个清楚的出手和一个结果。
   - 图里正在动的是对手时，写对手出手，主角当场接住，一个来回。
   - 开场就要法相成形时，材质、尺度、手臂兵器放进开头部分，开场段只写触发、成形和第一下出手。
4. **特效过程与环境反馈**：能量平时贴附在兵器、衣甲上，发力才离体；写它怎样出现、蔓延、消散；可以延迟爆发（人先过去，身后才炸开）；再写一个环境的物理反应（积水整片跳起、石板翻起、古松被压得贴地）。快的一拍之后，可以接一拍极短的安静，让下一次爆发更重。
5. **音效**：`音效：A → B`，一两个最能卖这一刻的声音，写出变化（巨响 → 死寂；环境声 → 细节声）。箭头用 →，不用表情符号箭头。

**全文最后单独一行写：`严禁画面生成字幕。`**（长片每一段都写。）

**台词**：写成叙述句，接在动作后面，例如“白衣剑客在高空俯视着女刀客，淡淡地说：‘又是你。’”。一句只说一件事，短、冷，像真人说话，每段最多一两句；不写戏腔，不替观众解释剧情，不用“台词（谁，语气）：”这种括号格式。

## 五、写作规则

### 称呼
- **叙述里每一处都写名字，不写他、她、它**。角色写角色名（男主、女刀客、傀儡、巨兽），能量、兵器、技能挂上主人的名字（“男主的赤红电弧”“傀儡的铜锤”），物件也写名字（“绕着光核往里卷”）。多角色、多参考图时，模型分不清代词指的是谁。
- 台词引号里的话不受这条限制。

### 特效
- **近战刀光贴着刀锋**：一闪即散，在砍中处炸开。不写近战刀光离开刀身飞出去、扫出去，不写X形、十字、网、墙、阵（会生成满屏光棒和激光雨）。刀光多，靠挥刀的速度来写。
- **远程气刃**（剑气、弦气、扇风、拳罡）可以离体，但要有出处、有形、有去向：
  - 从兵器、琴弦、拳面上成形，出手的人在画面里；
  - 写成有体积的刃形，或借介质显形（撞开雨幕、掀起湖面的浪、把茶水推成水雾）；
  - 写清射向谁、命中炸开；多道时写成一道接一道连发，或按鱼群结构成群；
  - 写明“不是光柱，不是激光”；
  - 不写“无数道从四面八方斩向”，也不写人不在画面里、只有光在飞。
- **特效写成成片的体积，不写成线**：用团、蓬、片、层、浪（炸开一蓬电火、掀起一片火浪）。不用“一线”“亮线”“斩击线”“刃线”，也不写“劈出一道痕”“裂成两半”“撕开口子”。线会被画成细细的光线，显得弱。
- **量词和动词决定形状**：
  - 液体写“一大片河水、宽阔的河面、翻涌的浪头、奔流泼溅的水”，并写明“不是一条带子”；不写“一条、整条、河身、河头”。
  - 盖住液体用“盖、压、罩住河面”，不用“裹、包、缠、拧成一股”，否则会收成一个球或一股绳。
  - “一圈接一圈”容易生成同心圆，写成“由近到远一路推开”。
- **比喻要消歧**：“剑河、剑瀑、剑潮”要注明只表示群体运动，不出现真实的水。“核爆级”要注明“不是现代核武器画面，不出现蘑菇云”。
- **能量锁定**：材质，加怎么动，加不是什么，加色彩对冲。兵器上的能量写清覆盖范围（“剑锋只附少许细密红雷，红雷不覆盖剑身”），防止整把兵器被光吞掉。
- **两种能量相撞**：写两种材质怎样互相作用（剑身吸附雨水成一层带电弧的水膜，和火焰摩擦爆出拉丝火星；火雾被打散，炸开一层层水浪涟漪），不写“光芒对撞”。
- **大范围攻击**写清源头和扩散面（“赤雷只在地面铺开，不从天空劈落，不形成雷柱”），天地级的压制分上、中、下三层写。
- **无形的气劲借介质显形**：拳风写成“半透明的气压”生成不出来，要借茶水、湖水、尘土、落叶显形，第一次出现写大。
- 不写用手抓住、攥碎能量。
- 对方的措辞和能量锁定里的否定句冲突时，以能量锁定为准，换个说法。例如能量锁定里写了“不是影子”，就不写“塌进一滩墨影”，写“塌进一滩活墨”。

### 速度
- 高速移动写动作（急退、跃开、贴地冲锋），不写“化作残影、化作烟雾、化作一道光”，这会生成一团黑影。刀锋弧光、人冲过后身后的水花迟半拍炸开，这类痕迹可以写。
- **瞬移是本体沿清晰的轨迹换位**：原处留下残影、音爆环和空气撕裂；远处的残影还没散，近处的人已经刹停；衣发晚半拍才翻卷。
- **不写慢动作，不写任何持续和停住**：“持续约一秒半”“定在半空”“几乎静止”“骤然的寂静”都会让画面真的停下来。命中写成“一闪 → 立刻碎裂”。
- **闪帧**写在发生的那一段，写成“闪一帧……，一闪即过”，例如满屏白、黑底红色剑痕、漫画风的放射速度线，模型能直接生成。不写抽帧、定格、子弹时间、升格慢放。
- **静压再爆发**：大招前可以有一拍静压，环境声像被抽空；爆发时，天地、能量、群体同一拍爆发，不是特效依次出现。
- **快打**写清次数（交替攻防四次），全程跑动，不写滑步；翻转旋转不超过360度。

### 大场面
- **请神、神将降临、法相现身，打斗就是斗法**：降临本身就有神威，对手跟着升级成巨物，双方正面对轰到山崩地裂。真人大小一枪一条龙，会显得“太普通”。
- **法相、大招的出场有过程**：触发动作 → 气浪或空间扭曲 → 成形，成形的同时本体还在动；写清尺度，并和地标比较（“比山峰还高的300米法相”）；法相是实体，写清材质（流体金水与梵文、翻涌的墨色与金光）；一出现就压迫环境（竹林被压得贴地）；与本体同步出手；崩解时写清化作什么散去（漫天金雨与碎梵文）。只写“浮现”，会生成一段静止的揭示。
- **法宝斗法**：
  - 人随手一个动作放出法宝（随手一扔）→ 镜头跟着法宝追上半空，人缩成一粒火点 → 法宝飞行中一层层铺开变大，写明“不是一块固定大小的布” → 在对手上方俯视，从上往下盖住、压住对手 → 对手挣扎、冲开一处，法宝再压下去 → 从里面燃起烈火爆开 → 法宝飞回人身上。
  - 只写两件东西本身，不掺小单位。法宝脱手后不再和人连着，写成一直连着，动效会很奇怪。
  - 每段写两到四个连续的形态变化。只写“法宝在天上兜住对手”，生成出来几乎是静止的。
  - 跨好几个量级的变化（手里一条绸带直接变成遮天）生成不出来；涨大一两圈、涨到比整片空地还宽可以。
  - 远景里的人写成“那一粒火点”“那个小小的红影”，手势照写。法相斗法时，本体站在法相胸前，与法相同步出手。
- **遮天的写法**：能量从人身上持续往外铺开，尺度靠镜头超广角高速后拉升空来完成，人迅速缩成天上的一个小点；遮住多少，靠下方的殿墙、飞檐一处接一处被红影吞没来表现。
- **控场型角色**（御剑、御龙、施法）只做两三个手势，每个手势是一道指令，天地同一拍响应；召来的东西从远处赶来，不在身边凭空生成。
- **群体用鱼群结构**（万剑、龙群、飞魔）：每一群有前部、中段、尾部，有宽度、厚度、纵深；前部是错层的锋线，中段上下换层，尾部追入回填；转向时前端先转，中段顺势，尾部延迟；摄影机在群外拍，不追单个；不写剑墙、剑板、同心圆、机械螺旋。
- **终结**：主角和他最大的力量同步出手（本体与法相同步挥拳；或者满天的雷、整片的火随他这一击一起砸下）→ 对手全力迎上，正面相撞，一方被压得节节后缩、压灭 → 冲击由近到远推开，地标依次崩塌，镜头被推到超大全景 → 巨物化作漫天的材质散去。终结是成片压下来的体积，不是一条线。
- **终结画面挂了形态参考图时，写成走到那张图的过程**：斩中处先往里收，从小涨大，一步步吞进对手；镜头同时被冲击推着倒飞，掠过一个个地标；退到位时才写“画面正好成了@图片N的样子”，再接崩散和扩散。@写在过程的终点；如果段首就写“超级远景，构图照@图片N”，生成出来会瞬间切到那张图。图里对手还剩哪一部分在外面，斩中的位置和吞进的顺序就要和它对得上。
- **收尾的巨物写完整的、会动的形象**，由对手自己的材质组成（河水倒涌堆成巨人），不用一只巨眼这种局部。

### 动作
- 招式用具体的武术动词：刺、挑、撩、抹、截、削、卸力、回马枪、地堂平削、踏壁折返。每个动作借上一个动作的力，借护栏、木柱、断梁换高度。
- 击飞写成分段轨迹：撞断什么 → 撞穿什么 → 砸进什么。高速移动时，每踏一处必碎。
- 道具来路连续：扔出去的要写怎么回来，插在地上的要写拔起来，不写扔出去又凭空出现在手里。
- 开场主角必须在画面里出手，不单独拍一道特效在飞。
- 特写只在和动作连成一体时出现；眼神特写、换武器的过程、微距质感、蓄力摆拍，都不单独成段，交代因果的过渡镜头会拖慢节奏。
- 不写这些套路：擦着鼻尖而过、差一毫米躲过、切断发丝、相撞后双向弹开、对视之后再出手、蓄力停顿、后仰闪避。

## 六、镜头小字的写法

国内有 AIGC 创作者用“镜头名 + 一行小字”的写法配镜头，小字就是写给模型的提示词。要点：
- 镜头名（无人机超广角、中景）只是标签，可以省；真正产生感觉的是小字。
- 小字只写一件事：画面怎么动、有多快、被什么推动、画面里的材质怎样反应。
- 常用四种手法：
  - 把镜头当成被卷进打斗的人：被激波推开、被迫让出距离、只捕捉到残影；
  - 用数字写距离变化：400米 → 180米 → 80米；
  - 写速度留下的痕迹：音爆锥、动态模糊、末端骤然减速；
  - 写材质的物理反应：衣摆撕裂、暗影沿石阶蔓延。
- 焦段可以翻成感受来写，不写毫米数。例如长焦写成“整群墨龙被压成一道逼近的锋线”，超广角写成“天洞下男主只是一粒火点”。
- **掩埋转黑**：烟尘迎面扑来，把镜头整个埋住，画面短暂变黑；下一拍，一道光从黑暗里割开烟幕。适合接大招。
- **跟东西飞一趟**：跟着刀光、跟着被打飞的碎块、跟着召回的兵器飞出去，到落点再切。

## 七、长片与台词

**流程**：先交设计方案，不直接写提示词。方案包括素材分工、每段30秒的主线和结尾钩子、双方技能、台词草稿、需要生成的道具图和首帧。设计里没定的点先问，不写“可以整段删掉”的可选段。故事定了，再一段一段写，每段生成后按反馈改完再写下一段。

**多段衔接**
- 每段都是一份完整的提示词，写8段，每段五个成分。
- 首尾相接：上一段的最后一拍就是下一段的第一拍；场景第一句写“承接上一段：……”。
- 下一段的首帧直接换一个新机位，不复制上一段的尾帧。
- 每段都重新完整写出场人物的外观、能量锁定和朝向句，逐段沿用同一句，不写“同上”。
- 参考图编号全片统一，@图片1永远是同一个人。

**台词**
- 叙述句，短、冷，像真人说话，每段最多一两句，全片十句以内。
- 不写戏腔（“孽畜，受镇”），不写替观众解释剧情、互相介绍身份的话。
- 请神、念咒用正式称号。
- 写明“台词为中文，男声／少年音”。有台词也不写配乐。全文最后照样写“严禁画面生成字幕。”。

**神话打斗重想象力，不考据**：技能按画面够不够新、够不够狠来设计，像打 Boss 一样分阶段，每一阶段换一套打法；不去翻原著凑设定。

**剑修**：优先用御剑（两指一引，剑自行出鞘飞斩、回旋、悬停，再回到手中）；大招用万剑，写成上百柄实体长剑，剑光贴在每一柄剑刃上，不写剑光飞出去。

## 八、视频反推

1. 先读时长、尺寸、帧率；用 ffmpeg 检测黑帧（`blackdetect=d=0.02:pix_th=0.10`）和切镜点（`select='gt(scene,0.35)'`）。
2. 每秒抽6帧拼成联系表看动作。每秒只抽2帧，会漏掉一半动作，还会把0.03—0.1秒的黑帧误写成停顿。
3. 全片最亮眼的一镜，按每秒15帧把前后一两秒连起来看，先弄清画面主体是谁、是哪一下打出来的。只看几张单帧，容易认错主体。
4. 量调色：用 `signalstats` 读饱和度和亮度范围，再看高光压没压、暗部是死黑还是发灰、有没有灰雾和颗粒。写成一句质感句，放进开头的场景描述里。

成稿：
- 动作密度照原片：原片一秒切三四次，每段就写两到四个连续动作。
- 原片看起来凝滞的一两秒，也不写成停住。
- 闪帧写进发生的那一段。
- 模型一条最长30秒：原片超过30秒，按剧情拆成最少的条数，前一条的结尾做钩子；原片在几处场景之间硬切的，写在同一条里，开头分别描述每处场景，正文用“镜头硬切到……”带过去。
- 只说“反推”就按画面还原，保留原片的结局；说“强化”，新增的设计要单独说明。
- 不虚构看不到的东西。

## 九、把旧提示词改写成这种格式

**保留**：原稿每个镜头的招式编排和武术术语；标志性的镜头设计；能量“死死贴附”在衣甲兵器上的写法；两种材质相撞的写法；法相的材质；三级碰撞的分级。

**替换**：

| 原稿写法 | 改成 |
|---|---|
| 0.05—0.15秒抽帧、定格、子弹时间、升格慢放、Time Ramp | “闪一帧……一闪即过”，全局写“动作全程不停”；连“不定格”这类否定也不写，免得把词带进画面 |
| 三级碰撞：抽帧、负片、鱼眼、泛光 | 轻碰闪一帧黑白冲击，镜头轴向微震；重碰放射状冲击，受力一方猛沉或回弹，流体炸开成三层；大招闪一帧全屏负片白，画面中心鱼眼畸变；都一闪即过 |
| 后仰规避、擦着鼻尖而过 | 侧身卸开、擦过肩甲 |
| 化作残影、化作闪电、化作巨剑 | 本体沿轨迹冲过，身后拖着残迹或剑光 |
| 定格姿态、仿佛一切静止 | 落地顺势俯身，紧接下一个动作 |
| 缓慢入鞘、缓慢后拉、画面渐暗、完美落幕 | 一个干脆的动作加冲击推镜，写完扩散就结束 |
| 法相“轰然浮现” | 触发 → 气浪 → 空间扭曲 → 材质堆高成形 → 和地标比尺寸 → 压迫环境 |
| 环形气浪、一圈圈伏倒 | 向四周排开，由近到远一片接一片压弯 |
| 运镜参数清单 | 翻成每段的镜头小字 |
| 【硬性锁死】【负面提示】长清单 | 落进能量锁定和否定句，不照搬清单 |
| 12—15个镜头 | 按动作的连贯合成8段 |

## 十、自检

- 能量、敌人、锚点、奇观，能在图里找到来源吗？有没有整句搬范例的画面描写？
- 把功能标题排成一列：多数段在重复加密同一种交锋吗？新机制、变大、换地点是不是各最多一次，而且都在最后三分之一？能量有没有超过3种？
- 有没有局势图段？巨物给到超远视角了吗？法宝有没有写成一直被人抓着、连着？
- 每段五个成分齐吗？镜头小字写的是感受，还是只写了机位名？每段交锋，双方都在出手吗？
- 全局有没有写成“背对镜头”？有没有写成镜头被主角逼退、迎着主角后退？
- 每段的镜头小字都先写了镜头在主角哪一侧吗？升空、举兵器、变身这些不是交锋的段落写了吗？
- 每张图的@旁边写清图里是什么了吗？形态参考图在正文出现的那一段有没有再@，@是不是写在过程的终点？
- 同一个人脚下的介质（沙、浅水、石板、半空）前后段接得上吗？
- 叙述里还有他、她、它吗？
- 开头有没有写成“会发生什么”（因果链、空间关系、镜头远近、声音清单、能量和技能的用法）？
- 液体、布料、光这些东西，量词和动词会不会把它画成错的形状？特效有没有写成一条线？
- 字数不超过5000（多数生成模型的输入上限）；5000以内不为压字数删内容，也不为凑字数加句子。
- 全文最后一行是不是“严禁画面生成字幕。”？全文有没有出现“最后镜头落回定型”？

**全文搜一遍这些说法，有就改**：

| 类别 | 说法 |
|---|---|
| 停住和慢放 | 慢动作、慢慢、缓推、定格、定在、静止、持续约、骤然的寂静、子弹时间、抽帧 |
| 化作 | 化作残影、化作烟雾、化作一道光 |
| 形状类能量 | X形、十字斩、刀网、剑网、刀墙、剑墙、刀阵、剑阵、四面八方 |
| 抓能量 | 攥住、攥碎 |
| 套路 | 擦鼻尖、差一毫米、切断发丝、离眉心一寸、双向弹开、对视再出手、蓄力停顿、后仰闪避 |
| 液体形状 | 一条（河）、整条、河身、河头、裹、包住、缠住、拧成 |
| 线式特效 | 一线、亮线、斩击线、刃线、撕开口子 |
| 结尾 | 最后镜头落回定型 |
| 代词（台词引号外） | 他、她、它 |

下面几种看上下文再定，不是一律删：
- “飞出去、扫出去、斩向”：刀光离开兵器才改，人被打飞、人持刀斩向对手可以。
- “浮现、显出”：前面必须有触发动作。
- “缓缓”：只能用在高潮后那一拍安静里。
- “一圈圈”：容易生成同心圆。
- “不是一条带子”这类否定句是故意写的，可以保留。

## 十一、范例：霜桥断刀（30秒）

下面是按本文规则写的完整示例，用来看格式和写法，不照抄内容；换一张图，画面全部重写。

## 附：几条最值钱的实测结论

| 现象 | 原因 | 怎么写 |
|---|---|---|
| 满屏飞的光棒、激光雨 | 写了刀光“扫出去、飞出去”“无数道从四面八方斩向” | 近战刀光贴着刀锋；远程气刃要有出处、有形、有去向 |
| 画面突然停住 | 写了“持续约一秒半”“定在半空”“静止”，或者段落结尾写成停住的姿势 | 命中写“一闪 → 立刻碎裂”；段落结尾写动作还在延续 |
| 一团黑影 | 写了“化作残影” | 写本体换位，原处留残影 |
| 河水变成带子、变成球 | “一条河”“裹住” | 一大片河水；盖、压 |
| 全片混乱 | 每段一个新机制、一段比一段大 | 多数段重复加密同一种交锋，升级只在最后三分之一 |
| 后10秒全浪费 | 终结太早，后面全是倒地和背影 | 终结在最后一段，写完扩散就结束 |
| 人物一直正对镜头 | 没写朝向，或者写了“镜头被主角逼退” | 全局写朝向句；逼退镜头的是对手 |
| 整片都是背影 | 全局写了“背对镜头” | 全局只管比例，背影只写在需要的段落 |
| 结尾回到开场画面 | 写了“最后镜头落回定型” | 写完扩散就结束，最后一行写“严禁画面生成字幕。” |
| 模型只照着开头生成，正文被略过 | 开头写了会发生什么 | 开头只写人、景、特效、技能是什么样 |
| 法相像一张静止的揭示图 | 只写了“浮现” | 写触发 → 气浪 → 成形，同时本体还在动 |
| 遮天的法宝生成不出来 | 一个物体从手里大小直接变到遮天 | 一层层铺开，尺度交给镜头后拉 |
| 终结显得弱 | 写成了一道亮线、裂成两半 | 写成成片压下来的相撞和扩散 |
| 中途切到另一张图的背景 | 多张参考图没有定场景 | 只管人物的图写“只取人物，不取背景”，场景只留一个出处 |
| 大场面“莫名其妙” | 镜头拔高看几路小单位包抄的局势图 | 大场面必须是一招打出来的后果；巨物才用超远视角 |
| 角色认错人、动作张冠李戴 | 叙述里用他、她、它 | 每处写名字，能量和兵器挂上主人的名字 |
| 升空、变身时人物正对镜头 | 朝向句只管交锋，这些段没写镜头方位 | 每段镜头小字先写镜头在主角哪一侧 |
| 画面瞬间切到参考图 | 段首就写“构图照@图片N” | 写成走到那张图的过程，退到位时才@ |
| 参考图不知道在哪一刻用 | 形态参考图只在开头挂了一句 | 正文出现的那一段再@一次 |
| 场面错乱 | 上一段砸进水里，下一段又站在沙滩上 | 理清每个人脚下是什么，要变就写一个动作带过去 |
