# 短剧角色、场景与道具资产提示词

本 Skill 将用户提供的《AI 绘图提示词模板（角色 / 场景 / 道具）》封装为可发现入口。原模板完整保存在 [references/public-asset-templates.md](references/public-asset-templates.md)，生成或修改提示词前必须完整读取。

## 使用范围

- 角色资产：定妆、全身棚拍、半身和头像，明确身份、外观、服饰、道具与姿势。
- 场景资产：默认空镜无人，明确空间结构、物件位置、材质、磨损和光线方向。
- 道具资产：单件展示，明确材质、尺寸感、使用痕迹、展示角度和背景。

保留用户已确认的角色身份、时代、造型、参考图、画幅和模型选择。缺少会改变角色或场景身份的信息时先询问；普通光线与镜头选择可按模板作明确的合理假设。

## 模板应用

1. 按资产类型选择原模板对应章节和参数库，只学习结构，不复制范例角色或剧情。
2. 使用具体物件、位置、材质、磨损和光线方向，不靠“高级感／氛围感”等空泛形容词。
3. 默认主体提示词使用中文、一段到底。多个资产可在提示词外加标签，保持每个资产独立可复制。
4. 角色默认哑光皮肤、双眼自然睁开、正常透视；全身资产要求从头到脚入画。头像或半身按模板替换构图要求。
5. 原模板中的中国／东亚人物、无人场景、胶片选择等是这套模板的默认值，不覆盖用户明确指定的人种、物种、角色状态或场景内容，不修改参考图中的既定身份。
6. 原模板“精简版无负面词”适用于角色主体提示词。场景和道具章节另有排除项示例：按用户要求和目标模型支持情况单独提供，不机械把所有排除项塞进主体。不同场景按时间／情绪选质感，不为了区分而破坏同场连续性。
7. 用户选 Midjourney 时提供可复制提示词；仅在画幅等参数已明确且受支持时附参数，不声称已提交生成。用户只要提示词时不调用生图。
8. 用户明确要求直接生成图片时，另行读取当前可用的 imagegen Skill，并用其规定的图片生成入口执行；本模板本身不是生成模型或 API。没有实际返回图片前，不声称已出图。

交付前按原模板第六节检查身份、构图、皮肤与眼睛、无人场景边界、空间布局、光线方向和质感，并优先满足本次用户明确要求。
