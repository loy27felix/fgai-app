# 剧本转文戏提示词 · FG 导演格式 v2

基于 Work-Fisher 免费公开开发版改编。原始说明与署名完整保存在 `references/upstream-skill.md`，禁止盗卖原 Skill。FG 的本次用户要求决定应用交付格式；来源信息写入任务元数据，不进入视频画面、对白或应用操作说明。

## 输入与剧情划分

完整通读确认的章节、角色、场景、道具和项目画风。原作的人物关系、族裔、物种、事件先后、动作、对白及明确的OS不改变，不为抽象心理虚构OS。

按目标模型实际支持的13／15／20／25／30秒与用户选择的固定或剧情划分模式工作。一片段是一条可生成视频，内部允许多个镜头。不能将3–4秒内部镜头拆成独立任务，不能靠快速念词、删词或重复对白塞进时长。对白超过时长时在完整句与剧情落点处另开片段。

划分围绕一个主要空间、一段关系变化与一个明确落点；转折、决定、发现、拒绝或新行动形成自然入口和出口。镜头数由信息与表演决定，不机械规定镜头数量或均分时间。

## 参考职责与主体

角色图锁定面部身份、发型、体型、服装、配饰和手中关键道具，棚拍背景不继承。场景图锁定空间骨架、出入口、前中后景、真实光源和可互动道具，不继承无关角色。画风图只参考媒介、色彩、光影和材质，不改变人物身份。使用实际素材名与稳定ID，不虚构引用，不绑定全章所有资产。

## 导演与表演

每个镜头一个叙事任务。信息、距离、权力、声音、道具或行动变化才推动切镜；连续短问答不机械逐句正反打。视线先发现目标，随后头肩重心响应；自然眨眼，不多人同步。近景用少量可见眼神、眉、唇、呼吸变化，避免空洞“情绪强烈”或肌肉术语。

摄影机有初始位置、路线、真实可通行空间和最终落点，转向有惯性。主光在场景中有真实位置，人物移动的受光变化必须合理。道具接触、接替与松手存在明确条件，写使用哪只手及动作反馈，不穿模。

每个主要角色建立年龄性别、音区音色、语速音量与句尾习惯的基础声线，跨片段逐字复用，只加载本段实际人声。情绪通过语气、停顿和呼吸体现。对白切至倾听者或空镜时使用原角色画外音继续，台词不遗漏、重复或转交别人。

## 跨段衔接

每段具体写出起始与结束人物方位、姿态、视线、手与道具、服装伤势、轴线、灯光和声音状态，不能只写“承接上一段”。下一段从这些状态出发。新角色或道具须有可见进入、取出、递入或遮挡原因。

允许同空间风景、道具插入、倾听者或其他人物反应作为下一段开场；必须说明动机，画外动作与声音继续、时间正常流逝。返回主体时从已经推进后的真实状态接回，不把人物复位，不借空镜无依据换边、换手、移位。

## 输出

严格采用 `references/director-prompt-format.md` 的完整导演格式，所有区块写为本片段实际内容。台词原文放在声音设计并与时间轴动作一致；音乐由已确认需求决定，默认无额外配乐。动画对应动画材质和表演，不强加真人毛孔。

仅输出调用方要求的JSON，完整提示词写入videoMotionPrompt。首帧写入imageGenerationPrompt；结束状态与下一段入口写入continuityOut。顶层skillAttribution保留来源，禁止写进生成提示词。局部修改时重发完整可用提示词，除非用户明确只要差异。

## 验收

- 原作对白、明确OS、因果与身份完整，没有默认亚洲外观覆盖原作。
- 时间轴连续覆盖0至所选时长，动作顺序、镜头与背景有具体内容。
- 参考职责明确，前后段姿态位置、道具、轴线和光声一致。
- 光源、通道、接触、摄影路径与空间物理成立。
- 完整格式，没有占位文本或用一句运镜代替导演提示词。
- 若有打戏，已经收到用户确认方向，再用wuxi-action-director-public设计攻防与反馈。
