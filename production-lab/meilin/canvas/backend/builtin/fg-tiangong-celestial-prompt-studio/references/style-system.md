# 天宫/云宫视觉系统

这份系统把四份参考文档里反复出现的有效规律，整理成可迁移的设计语言。它服务于新场景，不要求复刻任何单张图。

## 一句话定位

东方古典建筑的超尺度静默奇观：一个或几个如山岳般的白玉/朱漆/金瓦巨构悬于真实云海之上，极小的人物穿过其中，以真实光线、材料和空气透视制造敬畏、孤独与梦境感。

## 画面核心

### 主体和尺度

- 建筑、桥、阶梯、瀑布或宫殿空间是主角；人物只负责叙事动作或提供尺度。
- 优先 1–3 个巨大主体，不把画面塞成建筑素材拼贴。
- 人物默认约占画面高度 0.5%–1%；如果故事要求人物可辨识，可放宽，但仍要让空间压过人物。
- 建筑底部常隐入云海、薄雾或深渊，避免“平铺在地面上的模型展示图”。
- 人物可穿浅白、月白、淡灰、淡紫的汉/唐风衣袍；动作简单：行走、攀登、临桥、远眺、对着瀑布站立。

### 环境母题

从需求选择少数母题，不要全部同时出现：

- 白玉百米阶梯直入云海，阶线汇聚到深远灭点。
- 无尽朱柱/白玉柱的宫殿长廊，远端开门露出云海和浮宫。
- 跨越云峡的白玉拱桥、透明玉桥或多层平行桥。
- 宫殿之间的垂直天河、巨大瀑布和湿润黑岩台。
- 云上宫城、山脉般重檐屋顶、月洞门、回廊和少量悬浮楼阁。
- 高处亭台俯瞰云海、山峰和虹色折射。
- 必须有更强叙事时，可加入神圣实体、火环、孤舟或仙鹤，但它们不能无依据地抢走建筑主视觉。

## 构图和镜头

### 镜头选择

| 目标 | 机位与镜头行为 | 画面效果 |
| --- | --- | --- |
| 放大恐惧/敬畏 | 极低机位、超广角、向上仰拍 | 柱、檐、巨神或桥拱压过人物，体量最大化 |
| 做出建筑摄影感 | 平视或略高机位、35–50mm | 比例可信，适合阶梯、平台和宫殿关系 |
| 做无限延伸 | 长焦压缩、远距离观察 | 柱列、桥梁和屋檐层层叠入雾中 |
| 强调孤独 | 高位俯瞰/鸟瞰、深景别 | 人物成为巨大玉台或云海中的一粒点 |
| 加强电影前景 | 前景用檐角、柱础、栏杆、湿岩或枝叶遮挡 | 有前中后景和光学纵深，避免纯 3D 正面展示 |

不要把“居中对称”作为所有画面的默认值。仪式性建筑、长廊和正门可以严格对称；人物行走、瀑布侧景和高处远眺则用偏置、引导线或侧逆光更自然。

### 前中后景

1. 前景：湿玉台阶、盘龙栏杆、黑色湿岩、柱础、檐角或薄雾；可略微虚化。
2. 中景：一个清晰叙事动作或一座主建筑/桥/瀑布。
3. 远景：浮宫、云山、云海、开门、月亮或被雾吞没的屋脊；饱和度和对比度降低。

### 框中框和消失点

用柱列、檐口、拱门、桥栏或峡谷两壁自然框住远景；让重复柱列、台阶、护栏和水流共同指向一个主要灭点。不要同时设置多个互相竞争的视觉中心。

## 材料和物理反应

材质不是装饰词，要写清楚它如何接收光：

- 白玉：微微半透明、细小孔隙、柔和漫反射；湿润处变深，水膜产生连续镜面高光，刻纹边缘有柔亮反射。
- 透明/半透明玉桥：内部有细腻乳白结构和雕刻云纹，边缘受逆光，不能像塑料玻璃。
- 朱漆木柱：半哑光、轻微磨损、边角褪色；不要做成鲜艳塑料红。
- 深色琉璃瓦：整体吸光，只有窄而连续的金色边缘高光；檐下斗拱沉入阴影。
- 金箔/鎏金脊饰：小范围高光，作为节奏点，不要整片发光。
- 青铜：暗金氧化层、触摸磨损和雨水痕迹。
- 黑岩与地面：湿润后加深，薄水洼反射天空或暖光，接缝有泥、苔和沉积。
- 水与瀑布：受重力垂直下落，撞击处有白泡和细雾；不要把水写成无重力丝带。
- 云雾：体积层次、边缘受光、局部透出建筑；避免均匀的“白烟背景”。
- 织物：高空风让袖口、披帛和裙摆有方向一致的拖曳与运动模糊。

## 光线、色彩和空气

### 光线合同

先选一个主光方向，常用“侧后方低角度晨光”或“月光/雷暴前冷光”，再让所有高光和阴影遵守它。典型组合是暖金轮廓光 + 冷青灰/靛蓝阴影；体积光穿过雾和尘，不是均匀套滤镜。

- 亮部允许局部略过曝，暗部要沉下去，不要被抬成灰。
- 云海可以遮住建筑根部，形成自然的光层和尺度断裂。
- 远景使用蓝灰、紫灰或乳白大气散射，降低对比和饱和；中景保留结构；前景更有材质温度。
- 没有用户明确要求时，不显示一个贴在画面边缘的太阳；用天光、云隙光和反射光交代来源。
- 电影胶片颗粒可以很轻地加，不能用颗粒掩盖错误透视或材质。

### 默认色盘

冷白玉、雾白、青灰、深靛蓝、墨黑、暗朱红、少量鎏金/暖琥珀。昼景偏“冷白玉 + 暖金”，夜景偏“靛蓝 + 暗金/血红月光”。除非用户指定，不使用高饱和糖果色或霓虹色。

## 情绪与负面约束

目标情绪：庄严、寂静、神圣、辽阔、孤独、梦幻、带一点巨物恐惧；不是拥挤热闹、旅游宣传照或卡通仙侠海报。

默认 avoid：

`illustration, cartoon, anime, chibi, centered portrait, dense city cluster, generic fantasy castle, plastic CGI, glossy game screenshot, modern objects, random symbols, unreadable text, watermark, black bars, flat fog background, inconsistent shadows, floating water without gravity, oversized human, duplicate architecture`

“no text”只在用户没有要求文字时添加；如果用户要求海报文案，先把文字从画面 prompt 中单独列为 verbatim text，并建议后期排版，以避免生成乱码。

## 参考图使用原则

参考图可以提供：色温、云层密度、材质反射、风的方向、建筑密度、人物比例、镜头距离和整体情绪。不要自动保留参考图里的黑边、标题、logo、水印、人物身份或一模一样的宫殿轮廓。用户明确说“编辑这张图”时，才把它当作 edit target，并列出需要保持的 invariants。
