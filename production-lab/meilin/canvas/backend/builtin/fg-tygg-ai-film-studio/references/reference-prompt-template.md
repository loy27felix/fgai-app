# 结构参考视频提示词模板（规则 3.2.6）

本页专用于 Blender 粗预演＋资产图片生成成片；其他参考、编辑或延长模式按 [提示词规范](ai-video-and-asset-prompts.md) 分流。模板由本Skill独立编写，不照搬第三方案例剧情。

## 使用前的文件对照

未上传时，在正文外明确标注“以下为计划上传编号，需在即梦通过实际素材选择器插入对应标签”；给出 `本地文件 → 计划@标签 → 用途`。正文仍提供完整 `@视频1`、`@图片1` 等编号稿，不能因尚未上传退化为只写 `【某人物图】` 的抽象占位稿。

上传后以实际界面标签为准，名称/顺序不同就统一更新全文；手输`@`文字不证明素材已绑定。不伪造`@白模1`或平台没有的特殊锚点。每个生成单位单独有自己的映射；本地第08张图不一定是该单位的`@图片8`。

写稿时从现行记录对齐素材版本、主体身份、关键动作和局部时间。若涉及左右手、接触面或交接，明确人物自身侧别及动作起止状态，并在主体说明、有关动作段和段末保持一致；用户已纠正的关系直接采用，不仅写“原来的那只手”。已知冲突按 [写作核对](ai-video-and-asset-prompts.md#写作核对与按反馈修订) 解决，不能同时保留相反指令。

## 固定信息顺序，按内容增减

投喂正文第一块就是素材职责，前面不加故事简介、品质口号或内部说明。保留用户实测有效的结构与顶部职责，局部修订不自动整篇精简。以下是信息顺序，不规定时长、人数或分段数；正文标题可以沿用项目现有同义标题。动作规则见 [大体时间与自然表演](ai-video-and-asset-prompts.md#大体时间与自然表演)。

```text
素材职责：
@视频1：提供[实际采用的镜头路线、构图、空间拓扑、人物整体行进/相遇关系、关键事件先后及结果占位]；具体步法、发力、受力恢复、握持和面部表演按下文及既定媒介自然完成，不把代理摆动、滑移或倾倒当完整角色动作模板，不继承代理几何和识别色。[只对实际出现的关键道具声明其参照维度；未显示但剧情需要的道具，明确成片仍有且由相应图文补足。][本段确有简化手部时：只采用接触位置、归属和操作先后，不继承僵硬握姿或杆状外形。]
@图片1：确定[人物姓名]的面孔、发型、体型与服装；头部特写和正/侧/背三视图都是同一人，不复制设定板排版、展示站姿和背景，不生成多个同样的人。
@图片2：确定[另一人物姓名]的身份与服装，范围同上；所有视角属于同一身份。
@图片3：提供[场景]的外观与关键结构；实际布局和取景沿用@视频1，时段/灯光按下文。
@图片4：提供[关键道具]的外形与材质；位移、旋转、持有者及操作顺序按参考和下文。
[只在确有对应素材时追加风格/音频/同一角色状态图，并逐项明确范围；音频写清对应角色及采用声线、表达方式或原对白与节奏中的哪些属性。]

人物及道具：[可见代理特征，必要的首次位置/持续路线]对应[姓名或稳定称谓]（@图片1或已确认文字外观）；[逐一对应其余需区分人物，不只列一组衣服]。[对有歧义的首次入画、画外发声或再出现说明关系；多状态图仍为同一人。][关键道具归属；手别或交接影响剧情时，说明人物自身侧别、参照和状态变化。]

摄影与声音：[本段时长、画幅、视觉媒介]。[已确认摄影风格、手持强度与范围、长镜头/切镜策略；承接已有镜头路线]。[主光来源、色调、材质与声音基调。][有对白时按需说明语言、角色声线、台词与说话者口型对应、对白和环境声层次；语气与气息可随情绪变化，无对白则删去本项。]

动作与表演：以下时段为剧情的大体推进范围，段内按[参考中的整体路线与相遇关系]自然连续完成；[只补此参考缺少且符合既定媒介的角色动作和表演范围]。
约0–X秒｜[剧情阶段]：[人物想达成什么；触发、对象、反应和必要结果；关键情绪转折中可读的表情/声音变化，避免只写情绪名称；确认对白、声音及必要揭示。段内无逐动作秒数，也不必逐句安排反应。]
约X–Y秒｜[下一阶段]：[延续动作、信息和情绪；必要交互及结果；有意留白或画外关系。]

接续与连续性：[需要保护的身份、服装、入画和遮挡后关系；关键道具、伤势/情绪、未完行动与结果延续]。[本片必要的具体限制，避免重述全片；允许正常遮挡、光照变化与局部身体调整。]
```

完成稿替换全部内容占位，删除不存在的素材行。主要人物使用姓名；用户明确选择匿名角色时用稳定称谓。A/B、CHR编号、坐标与文件名留在工程说明，不能成为默认人物设定。

采用用户已有单视角图时，按该图实际内容改写，不谎称图中有三视图；新制人物板按 [人物图规则](character-image-assets.md)。连续剧情每段只引用当前人物/服装状态，继承前一段的知识、位置、持物和未完动作，不因分段重演已经完成的事件。

每个生成单位的正文独立完整，不能让用户自行拼公共前缀；同一单位的时间段不重复顶部素材职责。参考职责说明创作意图，不是模型硬约束接口或效果保证。镜头已有参考也仍写出已确认摄影和色光，只重申影响理解与揭示的关键镜头信息，不逐帧翻译F-Curve。近似时段不要求动作到点停住；准确时间只按具体同步/编辑需要局部添加。

## 完整示例：双人交还物品，单个连续镜头

以下为虚构的写法示例，不是用户项目或平台效果测试。假定已采用12秒连续镜头、轻微手持和中性偏暖风格，四张图分别为林禾、周岑、走廊、钥匙。`@`为计划编号，上传后须实际绑定。本例对应 [导演方案](director-plan-example.md)：圆柱＋球头带局部简化手部附件，提供递接关系；自然伸手、手指与抓握质感由视频模型表现。

```text
素材职责：
@视频1仅提供这个连续镜头的构图、跟随路径、人物整体位置与转向、钥匙的位置变化和交还时机；简化手部只参考接触位置、持物归属和接稳后释放的先后。不沿用圆柱球体、杆状手臂、块状掌形、僵硬握姿、识别色、中性展示光和滑移姿态，自然手指与抓握按下文表现。
@图片1确定林禾的面孔、发型、体型与服装，不参考展示姿势和图片背景。
@图片2确定周岑的面孔、发型、体型与服装，不参考展示姿势和图片背景。
@图片3提供走廊墙面、门框及地面的外观，路线和取景遵循@视频1，灯光按下文。
@图片4只提供同一串钥匙的外形、数量和材质，交还前由周岑持有，交还后由林禾持有。

主体对应：@视频1中的蓝色圆柱人物是林禾（@图片1），赭色圆柱人物是周岑（@图片2）。两人的真实服装按人物图，代理颜色不成为皮肤或新增配饰。

成片设定：12秒，16:9，写实生活短片。保持参考的一镜到底，侧后方跟随，轻微而克制的手持呼吸感，关键交还时不甩动。傍晚窗光为主要光源，室内暖灯补亮侧脸，中性偏暖、适度低饱和，肤色自然，暗部保留细节。声音以室内环境、脚步、衣料和钥匙轻响为主。

动作与表演：以下时段为大体推进范围，具体步法、伸手、抓握及反应沿参考的相遇与交还关系自然衔接。
约0–4秒｜靠近：林禾沿走廊走向门旁的周岑，目光被他手中的钥匙吸引，临近时自然放慢。周岑听到脚步转身相迎，两人在参考的位置相遇。
约4–8秒｜交还：周岑将右手的钥匙递向林禾，留意她是否接稳。林禾与他短暂对视，用左手接住；接稳后周岑才松开，钥匙发出轻碰声。身体、手臂与抓握自然配合，交接关系在原镜头中可读。
约8–12秒｜回应与离开：林禾握住钥匙，轻声说“谢谢”，原先的急切略微放松。周岑听见后以很小的微笑回应，不急着接话。林禾转向门，保留参考结尾的位置与停留，让这一刻自然结束。

连续性：这始终是同一条走廊、同两个人和同一串钥匙。左右均指人物自身；交还前钥匙由周岑右手持有，林禾左手接稳后周岑才松开，随后钥匙一直在林禾左手中，转身或遮挡不交换手别。脚步与抓握由真人身体自然完成，不复刻代理的无腿外形。整段不因时间分段而增加切镜。
```

无人物产品、机械过程或动物项目按实际主体重写职责与动作，不强行加人名、对白或手部动作。多个状态图说明“同一对象何时变成哪个状态”，不用状态图暗示自动新增镜头或替换身份。

多主体交互段可按“准备/逼近 → 发起者对明确目标行动 → 该目标响应 → 其他参与者继续行动 → 结果保持”展开，不必每镜另造格式。素材职责逐属性填写：未显示的道具、手部或细节不列入视频提供的动作参照；仍在对应时间段写出完整成片操作，不能因预演省略而把剧情也删掉。

## 完整示例：两名拦截者与连续突围

以下为独立虚构示例，未做模型生成测试。假定已确认18秒连续镜头及三名成年人的徒手交锋，图片1至4依次为江澈、韩峥、何远的人物图和仓库外观图；图片人物服装分别为灰衬衫、深蓝工装、棕夹克。代理路线与结果均已在参考中表达。编号为计划标签，不将示例素材当作真实附件。

```text
素材职责：
@视频1提供仓库通道、摄影机跟随与绕行、三人整体路线、入画关系、相遇和倒地占位。具体步法、拳脚发力、受力恢复与表情由真人自然完成，不继承圆柱摆动、滑移、倾倒模板和识别色。参考不提供手部或面部表演。
@图片1确定江澈的脸、发型、体型与灰衬衫；@图片2确定韩峥的脸与深蓝工装；@图片3确定何远的脸与棕夹克。各图的不同视角属于同一人，不复制展示姿势、背景或排版。
@图片4提供仓库铁架、灰墙和卷帘门外观；通道、门位及取景按@视频1。

人物及道具：蓝色代理是江澈；开场在通道前部的红色代理是韩峥；随后沿铁架侧面绕出的黄色代理是何远。三人按参考各自的路线入画和行动，何远未入画时仍在铁架后的原有位置，不提前移到江澈身旁。三人全程徒手。

摄影与声音：18秒，16:9，真人动作电影，一个连续镜头。沿用参考从通道跟随、侧绕交锋并退向出口的摄影路线，短促的手持冲击后自然回稳。高窗冷光与仓库暖灯交错，肤色自然，衣料和地面保留质感。急促脚步、衣料摩擦、打击与呼吸清晰，无对白。

动作与表演：以下时段是剧情的大体推进范围，局部动作在参考的路线与交锋区域内自然接续。
约0–5秒｜拦截：江澈想穿过通道离开，韩峥主动迎上阻拦。江澈察觉来势，侧让中还击，韩峥受挫后继续追进。江澈的目光随对方行动，攻防短促而有变化，身体不在每次出手后返回同一姿势。
约5–13秒｜夹击与突破：何远沿参考路线绕出铁架，寻找韩峥进攻后的空当加入。两人错位接替，彼此受阻时调整。江澈借韩峥追近之势以近身反击将他击倒，随即转向何远；何远趁势逼近，江澈挡开来拳，再以踢击使他失去平衡倒地。接触、受力及恢复连贯，倒地顺势落在各自参考区域，身体和衣服保持独立。
约13–18秒｜离开：两人失去继续拦截的能力后，江澈绕开倒地者快步到达出口，呼吸仍急，警惕地确认身后才略微松下肩膀。摄影机按参考完成结尾。

连续性：始终是这三个人。各人转身或被遮挡后仍保持自己的脸、服装与行动状态，正常光照冷暖不变成换装。韩峥先被有效反击击倒，何远之后因对应踢击倒地，不能同步响应同一攻击；倒地者不无因重新加入。时间分段不增加切镜，最终通过同一出口。
```

## 文戏动作段示例：试探与迟疑

以下文戏片段示例只展示相应的摄影/声音补充与动作段，使用时仍须按上方骨架给出完整素材职责、主体映射、摄影和连续性，不把片段冒充完整投喂稿。它们用于展示写作粒度，未做生成验证；时长、人物、情节、分段和表演强度不通用化。

本例假定24秒双人中近景连续镜头，参考已有隔桌对坐、末段男方欲起身后重新坐稳的走位。沈宁希望周远多留一会儿，又不愿直接挽留；周远准备告别，但谈话中开始迟疑。若实际参考结尾是离席，则先处理结果冲突，不能同时要求沿用离席和重新坐下。

```text
摄影与声音中的对白补充：自然普通话，沈宁声音清亮，周远声音低沉，各自声线连续。台词由具名角色说出，口型对应，雨声轻于对白。语气随谈话变化，不添加解释心事的旁白。

动作与表演：以下为剧情的大体推进范围，沿用参考的座位、整体移动和镜头，表情、视线与身体调整随交流自然衔接。
约0–7秒｜试探：沈宁看向周远，像随口确认一样问：“明天就走？”周远从窗外收回视线，低声答：“嗯。”听见回答，沈宁微微张开的嘴唇合拢，视线落向茶杯，没有继续问。周远察觉她欲言又止，目光仍留在她身上。
约7–16秒｜熟悉感：沈宁看着茶杯说：“这家店，你以前总嫌太吵。”听到“以前”，周远绷着的嘴角渐渐松开，浮起一点笑意，仍听着她把话说完，随后答：“今天还好。”沈宁抬眼看他，确认他也在笑，自己的笑意才变得自然。两人没有急着补话，拘谨在这次回应中缓和。
约16–24秒｜接受挽留：周远开始起身，沈宁刚刚舒展的笑意收住，抬眼说：“茶还热着。”听见这句，他停下起身动作，看向她，带着会意的笑重新坐稳，轻声答：“那再坐一会儿。”沈宁抿着的嘴唇松开，笑意重新浮现，目光没有再避开他。两人的关系延续前面的缓和，在安静中结束。
```

## 文戏动作段示例：争吵、悲伤与绝望

假定30秒连续镜头，前段能读清双人关系，末段按已采用参考靠近女主面部。陆遥以为仍能争取伴侣留下，程川已决定结束关系；参考提供陆遥从餐桌走近玄关、程川从入户门离开、陆遥留在屋内的路线和结果。程川的钥匙起初在夹克口袋内，离开前放到玄关桌面；行李箱随他离场。手部和面部细节由文字补足。

```text
摄影与声音中的对白补充：自然普通话。陆遥声音清亮，争吵时急促尖锐，受到打击后气息渐弱；程川声音低沉，疲惫而明确，各自声线保持连续。台词与对应说话者口型一致，倾听者不跟读。呼吸、钥匙落桌、滚轮和关门声按事件自然出现，环境声不盖过对白，无配乐和解释性旁白。

动作与表演：以下为剧情的大体推进范围，表情、呼吸和身体状态随事件连续变化。
约0–10秒｜争吵：陆遥走近程川，眉头紧蹙、下颌绷紧，质问：“你说走就走，有没有想过我？”程川答：“我们已经谈过很多次了。”听到“很多次”，她眉间收紧，向他摊开手，在他继续说下去前接话：“可你从来没听我说完！”她句末呼吸发紧，目光仍追着他等回应；程川抿住嘴，没有提高声音争抢。
约10–20秒｜悲伤：程川取出钥匙放到玄关桌面，说：“我不是出去几天。我不会再回来了。”听到“不会再回来”，陆遥准备反驳的嘴停住，摊开的手慢慢落下。她眉间的紧绷松开，眼眶泛红，轻声问：“……那我呢？”尾音发颤，泪水积起，她仍看着他，想找到一点动摇。程川神情难受，避开目光，却握住了行李箱拉杆。
约20–30秒｜绝望：程川低声说：“对不起。”拉着行李箱跨出门。陆遥轻声叫：“程川。”他没有回头，门随之关上。她目光仍停在门上，嘴唇动了动，最终没有再出声。一滴泪滑下，绷住的下颌松开，肩膀随不稳的呼气沉下去。她眼中的专注逐渐散去，不再追问，镜头留在尚未平复的呼吸和失去回应后的神情上。
```

本例以“争取回应 → 仍期待动摇 → 离场后希望落空”区分情绪阶段，而不是只提高哭泣强度。这是此处人物和故事的处理，不把绝望固定成安静、哭泣或任何一种面部模板。两例均保留事件触发、细微表情与跨段余韵，不为每个部位排时间表；台词与留白仍需按实际采用的时长核对，不将示例时长称为已计时通过。

## 文戏动作段示例：多人接话与反应

假定已采用18秒绘画式三维动画参考：三位朋友围桌，苏岚与梁川相邻，何青坐在对侧；何青发问时切到苏岚的倾听近景，问话声音跨镜延续，苏岚回答的话尾沿短弧线移向梁川，再留出他的回应。三人的代理、姓名、独立人物图及座位关系已在正文首部逐一对应。下文仅示范相应段落，不能单独替代完整投喂稿；为虚构写法示例，未做生成或朗读计时验证。

