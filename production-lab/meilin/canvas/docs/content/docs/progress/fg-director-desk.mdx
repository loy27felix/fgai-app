description: 第六板块的 3D 预演、云端工程和画布回写

画布底部工具栏打开「3D 导演台」。先选择已保存的 3D 工程节点可继续编辑，也可以从新工程开始；同一张画布可保存多个独立工程。工程记录和导出文件均遵守当前画布权限及版本校验，资源上传失败或云端版本冲突不得显示保存成功。

在导演台搭场景、排人物走位、设计摄影机和切镜，再使用「截图回画布」「调度说明回画布」「参考视频回画布」。参考视频可选择普通或深度画面；这些是浏览器本地渲染，不调用付费生成模型，产物会上传 NAS。关闭前先确认云端保存，读取失败禁止用空工程覆盖。内置或导入的工程模型资源随工程 JSON 保存；单次上传仍遵守服务器单文件限制。

「交给制作 Agent」保存工程及调度说明，再返回画布，把调度作为制作上下文。后续 WeToken 图片或视频生成仍由用户选择模型、Skill 和规格并确认执行，费用归属画布关联的故事项目。桌面 MCP 与直接调用 DirectorDesk 场景编辑工具的云端 Agent 适配尚未接通。

视频节点上方的「首帧」「当前帧」「尾帧」创建新的云端图片节点，保留视频来源与时间点。当前帧使用已播放节点的播放器时间；未启动播放器时打开选帧窗口。批量选帧入口仍在「提取素材」中，简单模式也可用。

并发配置：后台 Worker 20，Agent 活跃会话 24，WeToken 渠道及自定义中转 24，每账号最多 10 个活动任务。登录人数不受这些值限制；这是平台调度上限，供应商 429、配额或账号限制仍按实际响应处理。保留频控与账务核销，本次不进行付费压力测试。

技术来源与版本见第六板块 `THIRD_PARTY.md`。只更新第六板块独立服务、数据库与 NAS 资源，原五板块不变。
