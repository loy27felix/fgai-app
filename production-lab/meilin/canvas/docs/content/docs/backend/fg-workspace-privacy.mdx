---
title: FG 工作区数据隔离
description: 私人工作区与共享故事项目的访问边界
---

FG 的故事与项目及其画布面向公司成员共享。自由画布、独立广告工程、未共享的项目和素材按所有者隔离，平台管理员身份不授予读取其他成员私人内容的权限。

后端对画布列表、详情、保存、版本记录、资源及资产查询应用所有者或共享故事项目范围。广告网关对列表、打开、删除、恢复、清理和预算预留检查所有者。旧广告协作者记录不再授予访问权限；团队协作使用故事与项目。

成员主动发布的公司公共素材仍可通过公司素材库使用。系统管理、公司账务核销和公司音乐制作队列的操作权限独立于私人画布所有权，不通过管理员角色扩大私人画布查询范围。

自由画布列表默认仅显示自由画布，可切换到故事与项目；分类在服务端分页之前执行，浏览器项目查询缓存包含当前用户 ID。

画布所有者可以主动创建分享链接。链接持有人可查看分享的节点、连线和媒体；登录后可选择「复制到我的画布」。服务器复制公开快照以及独立媒体对象，以复制者身份原子保存私人画布和素材库记录。副本不关联原故事项目，不携带原作者聊天、任务状态或渠道密钥。

停止分享、链接轮换或过期会阻止新的查看和复制。已经成功保存的副本仍属于复制者；编辑副本不修改原画布，原素材移除不影响副本。传输失败或传输期间撤销分享时，不发布半完成的画布，并清理本次未完成复制创建的媒体。

复制入口是 `POST /api/public/canvas-shares/{token}/copy`，要求当前登录用户和可信来源；公开路径名称不使写操作变成匿名操作。分享的读取只开放准确的分享路径及 SPA 静态脚本，普通私人画布和素材接口仍需归属检查。

验收包含管理员 A、管理员 B、普通成员的互相访问检查，以及共享故事画布的读取和保存。健康接口成功不替代这些检查。
