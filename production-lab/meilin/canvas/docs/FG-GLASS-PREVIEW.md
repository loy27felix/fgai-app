# FG 前端玻璃视觉预览

本轮调整工作台外壳、创作首页、个人设置、管理中心导航与统计页面，并替换默认 FG 矢量标识和默认 Agent 球体。明暗主题使用同一布局、分别定义材质和文字对比度。

所有变更位于 `web/`：没有改 API、数据库、权限、模型默认值、费用策略、任务、媒体存储或业务命令。导航路径、筛选、导出、表格行距、模型选择、生成入口和 Live2D 配置保留。统计值来自现有接口。

## 发布与回退边界

只替换第六板块 `web` 容器。之前的前端镜像为 `fg-six-canvas-web:fg-20261007-audio-5ad98ac3e043`，源码基线为 `5ad98ac3e04374276d0dd5a65ee5ad12759df2fb`。

如需撤回本轮视觉预览，把 Compose 的 `CANVAS_WEB_IMAGE` 恢复到上述镜像，再仅更新 `web` 服务。不要回退数据库、backend、gateway、其他创作模块或此前的存储与音频修复。服务器发布过程会保留原环境的私密备份和前端镜像名称。
