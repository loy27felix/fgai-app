# FG 1.4.20：个人费用、广告更新与分镜恢复

个人费用入口位于通用账户卡，左下角资料和右上角头像共用。服务端始终绑定认证账号；客户端用户参数、管理员标记、共享项目身份均不能扩大范围。与管理员复用同一核销公式；未知费用保留待核对，失败请求不自动视为免费。筛选和分页在服务端执行，不输出调用正文或其他用户信息。

AdCraft 由 79405b3773942b5d41cea65ece3d605be6056ceb 更新至 fd2bd03e8756565384834dbfe8b0776915e470fb。合入品牌专业流程、界面双语、异步结果回写、断线/取消清理、素材窗口关闭、可配置媒体探测与 CFR 剪辑导出完整时间线。新建 FG 广告项目选择模式，已有项目保留自由创作。模式存入网关项目表并传给 AdCraft；品牌数据库、能力服务和 trace 读取使用当前应用配置，不用进程默认配置替代工作区配置。

桌面媒体拖到画布按落点上传并建立源节点；对话框支持图片拖入与粘贴。参考菜单保留草稿与多选，显示勾选及确认。上传和建立节点复用现有素材接口，不发起媒体生成。

重试进度统一使用上游原子创建方法，避免 FG 旧路径重复插入相同活动；保留终态提示、失败回滚、历史 JSON 键顺序的值不变校验和原操作人归属。

分镜校验区分声音说明和演出台词，仍检查说话人、顺序、用词及重复。模型成功与项目导入分开显示；失败恢复记录按账号、项目在浏览器会话中限量保存，并提供无付费生成的重试导入入口。

验证包括隔离 PostgreSQL 真实 SQL、React 交互、SQLite 迁移、双工作区品牌隔离、任务重试与 Agent 断线测试。本次不自动生成收费图片、音频或视频。上游全量测试存在已复现的历史断言失败，须与本次针对性验证结果分开记录。
