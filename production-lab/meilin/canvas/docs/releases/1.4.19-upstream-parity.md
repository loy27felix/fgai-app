# FG 1.4.19 上游功能适配

以 open-ai-canvas `cd694236f82e2851393cadc0150ebbde375cdc81`（v1.6.9.2）为上游基线，补齐近期差异审计中的产品能力。FG 使用独立版本、迁移编号与部署方式。

## 用户可见变化

- 本人对话可跨设备发现并继续，包含未绑定画布的全局对话。云端历史与当前浏览器的草稿、附件及选择题一起恢复，原请求身份保留。
- 同画布 Agent 占用和过期续聊检查减少重复执行；共享画布显示编辑占用，聊天正文保持账号隔离。
- 新增反馈建议、个人收件箱、图片/视频附件和管理员回复/归档。附件按资源归属检查，自动环境信息不附 URL 查询参数。
- 素材 Shift 连选、跨页批量操作按实际选中 ID 执行；模型图标解析、短剧命令入口开关和错误提示脱敏补齐。
- Responses 普通图文请求映射升级；可美 Seedream 5.0 增加专属参数与 1.5K 尺寸识别。按协议展示参数，保留 FG 现有渠道与账务。
- 管理员可查看服务商目录、核验 Key 并选择模型接入。已有渠道、凭据与价格不会自动替换。
- SDK 参数校验失败同步写回真实回执，独立 Agent runtime 与后端同步发布。此前已接的音频波形、连线反馈、预演和资产恢复继续保留。

## 数据与兼容

FG schema 61—64 依次处理目录来源、画布占用、反馈表与查询索引；历史迁移不重编号。已有图片、视频、分镜、账务和声音绑定保持。反馈附件纳入资源引用检查；不自动重新生成用户产物。

1.5K 分辨率的参数能力已接入，价格仍须命中 FG 已配置的对应档位；没有沿用上游将 1.5K 请求猜作 1K/2K 价格的回退，缺少报价时明确提示配置。

## 发布前验证

- 前端 125 项专项回归、63 项发布守卫与真实 React 对话面板 15 个场景通过；类型检查和 `/fg-six/` 正式构建通过。
- Linux ARM64 隔离容器完整运行 database、providercatalog、protocol、repository、canvas、handler、app 七个包，共 1,780 项顶层测试通过。协议使用现有支付插件产物与本次更新的声明式插件；未连接业务数据库或真实模型。
- 独立 PostgreSQL 验证 schema 60→64、重复执行、历史迁移身份与画布/任务保留；双连接同时续聊只准入一次，积分仅预留一次，失败预留释放后可重试。
- 部署前只做一次低优先级数据库备份并核对恢复目录，不新增定时任务。实际生产版本、入口与公告仍须在部署后核验。

真实双设备操作、反馈附件视觉效果、管理员所选渠道连通性与模型最终生成质量仍待用户验收；本轮未触发付费生成。
