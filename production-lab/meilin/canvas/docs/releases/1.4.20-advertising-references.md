# 1.4.20 广告参考图修复

普通图片上传后已加入消息附件，但对话框没有渲染附件，用户无法确认人物图是否仍然选中；后续普通上传还会清掉先前的 Product Main handoff。

上传用途明确为主产品图、人物参考图、其他参考图。人物图复用后端已有的 `character_main` 素材角色，不新增生成接口或收费请求。本次对话的参考图与节点显示在输入框上方，可逐个移除；多张人物图和主产品图同时保留。替换或移除主产品图时同步更新本次消息选中项，保留素材库原文件。

图片待分类或仍在上传时不能提前发送，避免消息漏带参考。参考仍按原业务协议随消息传递，发送成功后清空本次选中状态；生成节点的最终参考图与提示词仍需要用户核对。

用法：商品图选择“主产品图”；人像选择“人物参考图”，可一次多张或分批添加；从项目已有素材选择时点击 @，勾选后完成。消息中写清各图用途，例如“人物外观参考张三，商品外观参考主产品图，先给我方案与参考绑定供确认”。

回归覆盖分别上传商品与多人像、普通参考不清除商品、附件缩略图可见/逐个移除，以及人物角色元数据与图片 ID 随消息提交。编译在 Windows 完成，生产只替换静态广告前端及发布标识，不修改数据或发起媒体生成。
