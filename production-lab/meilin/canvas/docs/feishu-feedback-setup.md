# 飞书反馈与日报接入

入口：管理中心 → 平台配置 → 飞书反馈与日报。

当前日报只汇总从飞书接收的文字反馈，按问题、需求等分类，包含数量、提交人和内容摘要。它不包含模型费用、CPU 指标或所有任务的运行状态，也不替代美林日常助手。

1. 在飞书开放平台创建企业自建应用，添加机器人能力。在凭证页面取得 App ID 与 App Secret，直接填写到 FG 配置页，不要发到聊天里。
2. 申请机器人发送消息和接收单聊消息 / 群内 @机器人消息权限，并发布应用版本，把机器人加入反馈群和日报接收群。接收事件为 `im.message.receive_v1`。
3. 在 FG 填写 Verification Token、可选 Encrypt Key、接收群 Chat ID（`oc_` 开头），时区使用 `Asia/Shanghai`，设置日报时间。服务地址通常留空。
4. 回调选择 HTTP 请求地址，填写 `https://你的可信公网域名/fg-six/api/integrations/feishu/events`。此地址必须被飞书服务器访问，具有有效可信的 HTTPS 证书；内网地址和浏览器需忽略证书错误的地址不能作为已连通的证明。
5. 现在可以先保存配置并预览日报，不发消息。当前“接入与自动日报”开关同时控制接收和定时发送；关闭时不能完成真实事件接入，开启前先核对收件群与发送时间，随后在飞书完成 URL 校验。
6. 用单聊向机器人发一条 `Bug：某页面打不开` 或 `需求：增加某功能`，再在 FG 预览中核对。群聊使用 @机器人；飞书消息权限和可用范围仍需由企业管理员批准。

本轮保持关闭，不自动使用其他机器人的凭据，不自动给群发消息。网关只放行上述精确 POST 回调，原始签名字段转交后端验证；管理配置和预览仍需管理员登录。

官方说明：[接收消息](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)、[发送消息](https://open.feishu.cn/document/server-docs/im-v1/message/create)。
