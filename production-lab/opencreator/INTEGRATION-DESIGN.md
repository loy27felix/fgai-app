## 对公司有用的部分

视频翻译与双语字幕、视频下载、封面设计、文章与短视频脚本、智能配音。长视频自动切片和数字人仍是上游在开发的能力，不能当作已可用功能交付。通用图片、视频生成已有 FG 画布，独立模块优先解决翻译、配音和跨平台内容改编。

## 为什么不能直接共用一个实例

它依赖 Codex CLI / app-server、个人 Codex 配置和本地 Runtime。daemon 的接口使用一个全局 Bearer Token；文件、项目、会话、MCP、工具执行并没有 FG 的用户权限边界。直接让所有同事共享 Mac mini 的 Codex HOME 会混用文件和凭证。

## 独立接入边界

左侧新增“创作者工作台”，与故事、广告、自由画布平级。FG 网关鉴权后分配每个用户独立 Runtime、数据库、项目目录、Codex HOME 和内部令牌。工程仅本人可见，本版尚未提供跨用户分享。工程文件写入 NAS，数据库在私有状态卷中，每小时一致性备份覆盖个人 NAS 快照。没有主机用户目录、SSH 凭证或 Docker socket 挂载。

CLI 的 Responses、函数调用、自定义工具输入和 SSE 事件转换已实现并通过免费模拟测试。创作工具的非流式文本和单张文生图也通过 FG 任务接口；参考图生图和未适配工具明确返回限制。字幕识别、配音服务仍需公司可用渠道配置。

Codex 是服务端执行引擎，并非要求成员持有个人账号。模型列表使用公司已开放文本模型；内部凭据只允许对应 FG 用户发起任务。创作工具的自定义文本和 OpenAI 图片渠道在启动时统一配置。官方登录、个人 Provider 及存储重配置入口被网关禁止；Codex 专用原生生图路径不属于本版统一中转能力。

收费模型任务走原 FG 额度预留和计费流程，归属每位成员的独立 creator 项目，出账按 Reference ID 核销。预算默认 0 表示无项目上限，但受管理员设置的每月额度控制；不重复提交已登记且结果不确定的收费请求。原生 Codex 登录订阅渠道没有启用。

## 上线验收

发布验收包括服务健康、公司模型列表、两位用户工程隔离、免费工程保存恢复、NAS 备份与协议模拟。未执行收费生成；不得把模拟协议验证当作所有上游模型已实际跑通。服务依赖公司 NAS 和 Docker，用户退出不会丢失私有状态卷。
