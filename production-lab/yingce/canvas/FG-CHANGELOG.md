# FG Studio 更新日志

## 1.2.0 · 2026-10-01

- 第六板块接入独立制作工作台：故事立项、短剧 Agent、项目画布、技能、素材与创作记录。原五个板块继续独立运行。
- 故事选题关联项目档位、制作小组与人民币预算；生成请求归属用户、项目和画布。
- 接入 WeToken 文本、图片和视频渠道，按模型显示各自支持的比例、尺寸、分辨率、时长和参考素材方式。
- 生成前展示人民币费率及当前参数的估算；部分费用、未核验档位和按实际 Token 计费均明确标注。
- 账单按 Reference ID 精确核销，区分供应商实扣与模型估算。授权会话每分钟只读同步，CSV 仍可补充核对；会话过期暂停并提示重新授权。
- 后台查看账户账单总额、已归集费用、未归集费用，以及人员、项目和小组统计。积分、签到和充值入口关闭。
- 上传和生成的媒体使用 NAS 服务端存储；上传失败直接提示，不能把浏览器本地文件视为已保存。项目及记录保存在独立 PostgreSQL，定期备份到 NAS。
- 统一 FG 品牌与公司版本链接，修正系统磁盘统计异常。

当前限制：Gemini 3.5 Pro、Wan 3.0 上游路线暂不可用；未实测规格不宣称已核验价格。费用以供应商出账后的实际核销为准。
