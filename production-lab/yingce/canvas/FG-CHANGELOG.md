## 1.2.1 · 导演助手、工程恢复与画布操作 · 2026-10-03

- 3D 导演台内置助手接入 FG 服务端文本任务，读取原项目内置 Skill 与工具协议，直接搭景、修改走位和运镜；支持讨论/执行、选中对象或时间范围、定位与撤销。文本请求记录及费用归入当前故事项目。停止按钮取消服务端任务，未运行付费验收。
- 底部 3D 入口改为当前画布工程库，可恢复已保存工程、新建多个工程，或在独立窗口分别编辑；原工程、导出截图和视频保存在 NAS。自由画布与故事画布使用同一套功能。
- 团队 Worker、Agent 会话、WeToken 渠道与中转并发上限调为 100；单人同时排队或运行任务仍限 10，频控与已有预算参数保留。上游额度与机器容量仍可能限制实际吞吐量，未进行付费并发压测。
- 修复节点 Skill 选择弹窗立即关闭；画布 Agent 统一保留实际技能库入口，真实读取技能及配套文件。主页与 Agent 支持上传 Word .docx、PDF、Markdown 等资料，原文件保存到 NAS，正文进入模型上下文；扫描 PDF 无文字时明确提示。
- 回车统一换行，Ctrl/Cmd+回车或按钮提交，引用候选菜单内回车仍确认选择。修复白天模式全景环视按钮；深色画布增加柔和渐变、自定义背景图片上传及尊重减少动态效果设置的平移惯性。
- 修复音轨提取误用 MP4 文件名，使用 MP3 容器，必要时回退 WAV；原片无音轨时给出正确提示。支持 app.tapnow.ai 与旧域名的正式分享链接，兼容 `n155` 等字符串短编号；私有或未分享链接仍需要先在 TapNow 发布分享。TapNow 与 LibTV 外部媒体先归档 NAS，再提交画布；失败明确提示，不把第三方临时链接视为已备份。
- 已包含上游 42f14cd7 的孤儿步骤任务接管恢复修复，防止恢复过程中重复建单。无需数据库迁移，只更新第六板块服务，原五个板块不重启。

## 1.2.0 · 团队并发、视频提帧与 3D 导演台 · 2026-10-03

- 后台制作任务并发提高到 20，制作 Agent 活跃会话提高到 24；WeToken 渠道及自定义中转请求并发提高到 24。每人最多 10 个排队或运行中的任务，满额后需等待已有任务完成再提交。已接受的任务按团队并发上限调度。频控、审批、报价和人民币费用核销保留；未调用付费模型做并发压测。
- WeToken 确认 Wan 3.0 权限开放，启用文生视频与图生视频；Gemini 3.5 Pro 保留多模态文本配置，但因供应商暂未授权继续停用。本次仅核验配置、只读模型目录和人民币报价，不付费生成。
- 视频节点顶部提供首帧、当前帧、尾帧入口；当前帧读取节点播放器的实际时间，批量选帧继续保留。截帧上传 NAS 并生成可追溯的图片节点，不修改原视频。
- 画布加入 FG 3D 导演台，复用 DirectorDesk 0.4.10：场景模板、人物走位、多摄影机、运镜时间轴、普通及深度参考视频。3D 工程绑定画布并保存到 NAS；截图、调度说明和参考视频回写当前画布，可交给制作 Agent 继续制作。
- 导演台网页版不开放桌面专用 MCP、本机 AI 密钥和自动更新；制作 Agent 仍使用 FG 的服务端 WeToken 渠道。场景直接由 Agent 调度的桌面能力不在本次宣称已接通。
- 同步 open-ai-canvas main 至 f0302045：新增 Dola-pool 独立 Seedance 协议与测试（修正复用 Kling 轮询路径的问题），上游演示链接调整不替换 FG 的公司入口。无数据库迁移，原五个板块保持不变。

## 1.2.0 · 团队开放更新 · 2026-10-02

- 第六板块向所有已登录的平台成员开放；后台管理、审核故事和记账设置仅超级管理员可操作。
- 故事投稿先审核再入库；故事详情保留原作、人物原型、梗概、冲突、视觉风格与市场方向。
- 故事项目和关联画布在团队内共享，一部故事可关联多张分集、试片及制作画布；个人自由画布仍独立。
- 共享画布保留版本校验和原创建者；同一版本同时保存会返回冲突，不能覆盖先保存的修改。素材仅随明确共享的故事画布开放。
- 小组支持新建、改名、停用和成员调组；请求保留发生时的小组，历史费用不会因调组重新归类。
- 模型改为简短名称；单渠道模型直接选择，人民币金额放在生成按钮旁，去掉输入框下方的计费说明。
- 创作输入框、节点和画布 Agent 增加明确的 Skill 选择入口；Agent 首页优先进入故事项目。

这次验证不调用付费生成。报价沿用已匹配账单及已核对公式；按实际 Token 计费的请求仍需要生成后出账核销。

- 接入 WeToken 文本、图片和视频渠道，按模型显示各自支持的比例、尺寸、分辨率、时长和参考素材方式。
- 生成前展示人民币费率及当前参数的估算；部分费用、未核验档位和按实际 Token 计费均明确标注。

- 后台查看账户账单总额、已归集费用、未归集费用，以及人员、项目和小组统计。积分、签到和充值入口关闭。
- 上传和生成的媒体使用 NAS 服务端存储；上传失败直接提示，不能把浏览器本地文件视为已保存。项目及记录保存在独立 PostgreSQL，定期备份到 NAS。
- 统一 FG 品牌与公司版本链接，修正系统磁盘统计异常。

当前限制：Gemini 3.5 Pro、Wan 3.0 上游路线暂不可用；未实测规格不宣称已核验价格。费用以供应商出账后的实际核销为准。
