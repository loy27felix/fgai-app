# FG 1.2.0 运维补充

FG 产品版本与上游版本分离。产品更新来自公司仓库 v1.2.0；上游 v1.6.0 / 42f14cd7 用于技术追溯。

资源上传必须服务端成功，失败向上传播；浏览器缓存不能替代 NAS 持久化。旧本地缓存只用于恢复已有资料，新增上传不返回 pendingRemoteUpload 成功结果。

网关每分钟只读同步授权 WeToken 费用会话。会话不存密码、不提交 Git，只 GET 固定账单接口，按完整分页成功后导入；会话过期暂停，CSV 保留。`fg_company_settings.wetokenFeeSync` 保存非敏感同步状态、时间与提示。费用表以 Reference ID 唯一、精确核销，未匹配金额不猜测归属。

生成前人民币报价覆盖创作工作区、画布输入面板和项目镜头制作台；Seedance 最低 Token 采用官方公开表。没有确定总价的文字和图片 Token 费用、未验证费率和自适应像素明确标注。实际金额以供应商账单核销为准。

验收：网关费用、匹配、报价和来源隔离 26 项测试；NAS 上传失败/成功 2 项测试；模型参数与图片尺寸 21 项测试；TypeScript 和 Vite 构建；后端 FG/Ark 适配测试；原应用镜像与启动时间不变；数据库 NAS 备份及原媒体读回摘要。

仍待完整验证：所有模型、输入方式、尺寸和时长的组合；Agent 批量审批报价；断电后的数据库完整恢复演练；正式 Cloudflare 域名素材入口；用户实际生产操作。会话过期需管理员重新授权。
