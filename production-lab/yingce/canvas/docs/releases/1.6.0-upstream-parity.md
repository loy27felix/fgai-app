放大编辑器中的设置浮层采用 AntD 当前弹窗上下文的层级，不再固定为 1100。真实 AntD 弹窗专项用例验证在 2500 层弹窗内仍能显示设置选项。

分镜错误区分 JSON 格式不合法与输出未完成。原任务结果和失败草稿不自动改写。保存结果核对入口支持对照台词、修改视频提示词、修正 JSON；只有用户明确确认时才允许本次导入的台词差异，记录来源任务与确认方式。章节版本、完整批次、引用、镜头格式、替换确认和保存回读检查保留，不发起模型调用。

数据库 FG82 对应上游78，仅为制作流水线角色补声音、样本、造型父角色及章节适用范围；1–81 的已发布名称与校验和不变。部署不执行全库备份，不删除工程、媒体或持久卷，不停用生产守护任务。

验证采用实际生成上下文、角色样音与引用编号、已保存草稿导入、项目英文偏好、AntD 弹窗、上游助手/引用/滚轮/复制/选章测试、前端类型及真实构建，以及隔离后端与迁移测试。没有提交付费媒体生成；模型生成画面的实际方向与表演效果仍需用户验收。
